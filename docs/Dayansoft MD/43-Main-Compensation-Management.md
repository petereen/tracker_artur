# Размер бүртгэх [Anchor](https://docs.dayansoft.mn/erp/main/d042\#%D1%80%D0%B0%D0%B7%D0%BC%D0%B5%D1%80-%D0%B1%D2%AF%D1%80%D1%82%D0%B3%D1%8D%D1%85)

![Size](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/09.main/30.d042/Size.png)

## Размер гэж юу вэ? [Anchor](https://docs.dayansoft.mn/erp/main/d042\#%D1%80%D0%B0%D0%B7%D0%BC%D0%B5%D1%80-%D0%B3%D1%8D%D0%B6-%D1%8E%D1%83-%D0%B2%D1%8D)

Энэ цонхонд бараа, бүтээгдэхүүний **хэмжээ буюу размер (Size)-ийн лавлах мэдээллийг** бүртгэнэ.

Размер шинээр нэмэгдэх, нэршил өөрчлөгдөх үед энэ цонхонд бүртгэлээ нэмэх, засварлах боломжтой.

Бүртгэсэн размерын мэдээллийг бараа материал шинээр бүртгэх үед:

`Бараа материал → Барааны код → Тохиргоо`

цонхонд ашиглана.

![SizeProduct](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/09.main/30.d042/SizeProduct.png)

# 1\. Размер шинээр нэмэх [Anchor](https://docs.dayansoft.mn/erp/main/d042\#1-%D1%80%D0%B0%D0%B7%D0%BC%D0%B5%D1%80-%D1%88%D0%B8%D0%BD%D1%8D%D1%8D%D1%80-%D0%BD%D1%8D%D0%BC%D1%8D%D1%85)

`Үндсэн тохиргоо → Размер` цонх руу орно.

Шинэ размер бүртгэхдээ:

**Шинэ**
эсвэл `Ctrl+Insert` товч дарна.

Устгах болон засах үйлдэл нь бусад цонхтой ижил.
