# 🌐 Гадаадаас Dayansoft ERP системд хандах эрх нээлгэх [Anchor](https://docs.dayansoft.mn/support/d194\#%F0%9F%8C%90-%D0%B3%D0%B0%D0%B4%D0%B0%D0%B0%D0%B4%D0%B0%D0%B0%D1%81-dayansoft-erp-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B4-%D1%85%D0%B0%D0%BD%D0%B4%D0%B0%D1%85-%D1%8D%D1%80%D1%85-%D0%BD%D1%8D%D1%8D%D0%BB%D0%B3%D1%8D%D1%85)

Аюулгүй байдлыг хангах үүднээс **Dayansoft системийн мэдээллийн баазад Монгол Улсаас өөр улсын IP хаягаар хандах хандалтыг анхдагч байдлаар хаасан** байдаг.

Хэрэв та гадаадаас буюу Монгол Улсаас өөр улсаас Dayansoft ERP системд **зайлшгүй хандах шаардлагатай** болсон бол түр хугацаанд хандах эрх нээлгэх хүсэлт гаргана уу.

👉 **[Гадаадаас хандах эрх нээлгэх хүсэлт илгээх](https://dayansoft.bitrix24.site/PublicIPaccess/)**

> 🔐 **Аюулгүй байдлын зорилго**
> Гадаад IP хаягаас мэдээллийн бааз руу шууд хандах боломжийг хаасан нь байгууллагын мэдээллийг зөвшөөрөлгүй хандалтаас хамгаалах зорилготой.

## 📝 Хандах эрх нээлгэх дараалал [Anchor](https://docs.dayansoft.mn/support/d194\#%F0%9F%93%9D-%D1%85%D0%B0%D0%BD%D0%B4%D0%B0%D1%85-%D1%8D%D1%80%D1%85-%D0%BD%D1%8D%D1%8D%D0%BB%D0%B3%D1%8D%D1%85-%D0%B4%D0%B0%D1%80%D0%B0%D0%B0%D0%BB%D0%B0%D0%BB)

**1.** Гадаадаас Dayansoft ERP системд нэвтрэх үед гарч буй **IP хаягийн алдааны мэдээллийг харна.**

**2.** Тухайн алдааны зургийг авна.

**3.** **Public IP хандах эрх нээлгэх хүсэлтийн форм** бөглөнө.

**4.** Алдааны зургийг хүсэлтэд хавсаргана.

**5.** Хандах шаардлагатай хугацааг хүсэлтэд тодорхой бичнэ.

**6.** Даянсофт ХХК хүсэлтийг шалгаж, тохиргоо хийсний дараа бүртгэлтэй **мэйл хаягаар хариу илгээнэ.**

> ⚠️ **Чухал — Урьдчилж хүсэлт илгээх боломжгүй**
> Хандах гэж буй **тухайн байршил IP хаягнаас Dayansоft системд нэвтрэх үед гарсан IP алдааны зургийг** заавал хавсаргана. Иймээс гадаад явахаасаа өмнө урьдчилан хүсэлт илгээх бус, тухайн байршлаас системд нэвтрэх үед хүсэлт гаргана.
>
> ⏰ **Санамж — Хандалт автоматаар хаагдана**
> Хүсэлтэд заасан **хаагдах хугацаа дуусмагц тухайн IP хаягаас Dayansoft ERP системд хандах эрхийг хаана.** Иймээс шаардлагатай хугацаагаа хүсэлт гаргахдаа зөв бөглөнө үү.

* * *

# ⚠️ Public IP хаяг өөрчлөгдөх боломжтой [Anchor](https://docs.dayansoft.mn/support/d194\#%E2%9A%A0%EF%B8%8F-public-ip-%D1%85%D0%B0%D1%8F%D0%B3-%D3%A9%D3%A9%D1%80%D1%87%D0%BB%D3%A9%D0%B3%D0%B4%D3%A9%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6%D1%82%D0%BE%D0%B9)

**Public IP address** нь тухайн ашиглаж буй интернетийн холболтоос хамаарч өөрчлөгдөж болно.

Жишээлбэл:

- 📍 өөр байршилд шилжих;
- 🌐 өөр Wi-Fi ашиглах;
- 📱 гар утасны hotspot ашиглах;
- 🔄 интернетийн холболтоо салгаж, дахин холбох;
- 📡 өөр интернет үйлчилгээ ашиглах

үед Public IP хаяг өөрчлөгдөж болно.

> ⚠️ **Анхааруулга**
> Өмнө нь тохируулсан Public IP хаяг өөрчлөгдсөн тохиолдолд өмнөх тохиргоо үйлчлэхгүй. **Шинэ IP хаягийг дахин тохируулах хүсэлт гаргах шаардлагатай.**
>
> ❗ **Чухал**
> Гадаадаас хандах Public IP тохиргоог **түр хугацаанд, хязгаарлагдмал тоогоор** хийх боломжтой. Иймээс байршил, интернетийн холболтоо тогтвортой ашиглахыг зөвлөж байна.

# 🛰️ Starlink ашиглаж байгаа бол [Anchor](https://docs.dayansoft.mn/support/d194\#%F0%9F%9B%B0%EF%B8%8F-starlink-%D0%B0%D1%88%D0%B8%D0%B3%D0%BB%D0%B0%D0%B6-%D0%B1%D0%B0%D0%B9%D0%B3%D0%B0%D0%B0-%D0%B1%D0%BE%D0%BB)

Хэрэв танай байгууллага **Starlink интернет** ашигладаг бол Public IP хаяг нь Монгол Улсаас өөр байршилд бүртгэгдэх боломжтой.

Иймээс Монгол Улсад байрлаж байгаа хэдий ч Dayansoft систем таны холболтыг **гадаад улсаас хандаж байгаа мэтээр таних** боломжтой.

> ⚠️ **Анхааруулга — Starlink**
> Starlink ашиглаж байгаа үед Dayansoft системд нэвтрэхэд гадаад IP хаягийн хязгаарлалтад орж болох тул шаардлагатай тохиолдолд **Public IP хандах эрх нээлгэх хүсэлт** гаргана уу.
>
> ❗ **Чухал**
> Starlink интернет ашиглаж байгаа үед **татварын системд хандах боломжгүй байх** тохиолдол байдаг. Татварын систем ашиглах шаардлагатай бол Монгол Улсын IP хаягаар холбогддог интернетийн өөр сувгийг ашиглах шаардлагатай байж болно.
