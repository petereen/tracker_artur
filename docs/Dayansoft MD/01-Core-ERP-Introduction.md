# 🏢 Dayansoft ERP систем [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%8F%A2-dayansoft-erp-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC)

**Dayansoft ERP** систем нь санхүү, нягтлан бодох бүртгэл, менежмент болон бизнесийн өдөр тутмын үйл ажиллагааг цогцоор нь удирдах **мэдлэг шингэсэн, мэргэжлийн ERP систем** юм.

Монгол Улс болон олон улсад мөрдөгдөж буй нягтлан бодох бүртгэлийн стандарт, шаардлагад нийцүүлэн байгууллагын санхүү, бүртгэлийг хөтлөх, хянахын зэрэгцээ өдөр тутмын бизнесийн үйл ажиллагаанаас бий болсон мэдээллийг **удирдлагын шийдвэр гаргалтад ашиглах боломжтой цэгцтэй мэдээлэл** болгон нэгтгэхэд чиглэдэг.

> 📌 **Өнөөдрийн байдлаар 2,500+ харилцагч байгууллага** өдөр тутмын бизнесийн үйл ажиллагаандаа Dayansoft ERP системийг ашиглаж байна.

* * *

# 💡 Бид ямар систем бүтээхийг зорьдог вэ? [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%92%A1-%D0%B1%D0%B8%D0%B4-%D1%8F%D0%BC%D0%B0%D1%80-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC-%D0%B1%D2%AF%D1%82%D1%8D%D1%8D%D1%85%D0%B8%D0%B9%D0%B3-%D0%B7%D0%BE%D1%80%D1%8C%D0%B4%D0%BE%D0%B3-%D0%B2%D1%8D)

Уламжлалт байдлаар зөвхөн өнгөрсөн хугацааны баримт, ажил гүйлгээг нөхөн бүртгэж, сар, улирал, жилийн эцэст тайлан баланс гаргахад ашигладаг системээс ялгаатайгаар Dayansoft ERP-ийг **өдөр тутмын бизнесийн үйл ажиллагаанд тогтмол ашигладаг систем** байхаар хөгжүүлдэг.

Өөрөөр хэлбэл:

- **Өдөр тутмын үйл ажиллагаа**
- ⬇️
- **Мэдээлэл бүртгэгдэнэ**
- ⬇️
- **Нэгдсэн мэдээллийн сан бүрдэнэ**
- ⬇️
- **Мэдээлэл боловсруулагдана**
- ⬇️
- **Тайлан, шинжилгээ гарна**
- ⬇️
- **Удирдлага шийдвэр гаргана**

Ингэснээр байгууллага өнгөрсөн хугацааны тайланг гаргахаас гадна **өнөөдөр бизнесийн үйл ажиллагаа ямар байгааг бодит мэдээлэлд үндэслэн хянах** боломжтой болно.

# 🧠 Мэргэжлийн хүнд — мэргэжлийн багаж [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%A7%A0-%D0%BC%D1%8D%D1%80%D0%B3%D1%8D%D0%B6%D0%BB%D0%B8%D0%B9%D0%BD-%D1%85%D2%AF%D0%BD%D0%B4-%E2%80%94-%D0%BC%D1%8D%D1%80%D0%B3%D1%8D%D0%B6%D0%BB%D0%B8%D0%B9%D0%BD-%D0%B1%D0%B0%D0%B3%D0%B0%D0%B6)

Dayansoft ERP-ийн үндсэн зарчмын нэг нь:

> **Мэргэжлийн хүн стандартын дагуу зөв бүртгэл хийхэд саад болохгүй, харин мэргэжлийн бус хүн алдаатай бүртгэл хийх үед нь ойлгомжтойгоор анхааруулж, шаардлагатай тохиолдолд хориглох.**

### 👨‍💼 Мэргэжлийн хэрэглэгч [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%91%A8%E2%80%8D%F0%9F%92%BC-%D0%BC%D1%8D%D1%80%D0%B3%D1%8D%D0%B6%D0%BB%D0%B8%D0%B9%D0%BD-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87)

Нягтлан бодох бүртгэлийн стандарт, дүрэм журмын дагуу зөв баримт, ажил гүйлгээг бүртгэж байгаа тохиолдолд систем нь шаардлагатай үр дүнд хүрэх боломжийг хязгаарлахгүй.

### ⚠️ Мэргэжлийн бус хэрэглэгч [Anchor](https://docs.dayansoft.mn/erp/d012\#%E2%9A%A0%EF%B8%8F-%D0%BC%D1%8D%D1%80%D0%B3%D1%8D%D0%B6%D0%BB%D0%B8%D0%B9%D0%BD-%D0%B1%D1%83%D1%81-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87)

Стандарт бус, буруу эсвэл эрсдэлтэй ажил гүйлгээ хийх гэж байгаа үед систем:

- ⚠️ анхааруулах;
- 🚫 шаардлагатай тохиолдолд хориглох;
- 💬 ойлгомжтой тайлбар өгөх

зарчмаар ажиллана.

Ингэснээр систем нь зөвхөн **бүртгэл хадгалах хэрэгсэл** бус, хэрэглэгчид зөв ажиллахад туслах **мэргэжлийн ажлын хэрэгсэл** болно.

# 👨‍💻 20+ жилийн туршлага дээр суурилсан систем [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%91%A8%E2%80%8D%F0%9F%92%BB-20-%D0%B6%D0%B8%D0%BB%D0%B8%D0%B9%D0%BD-%D1%82%D1%83%D1%80%D1%88%D0%BB%D0%B0%D0%B3%D0%B0-%D0%B4%D1%8D%D1%8D%D1%80-%D1%81%D1%83%D1%83%D1%80%D0%B8%D0%BB%D1%81%D0%B0%D0%BD-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC)

Dayansoft ERP-ийг хөгжүүлж буй баг хамт олон нь салбартаа **20+ жилийн туршлагатай**.

Системийг хөгжүүлэхдээ:

- 📚 практик ажлын туршлага;
- 🧾 нягтлан бодох бүртгэлийн шаардлага;
- 🔍 аудитын туршлага;
- 👨‍🏫 мэргэжлийн зөвлөхүүдийн санал;
- 💡 хэрэглэгчдийн бодит хэрэгцээ

зэрэгт тулгуурлан тасралтгүй сайжруулдаг.

Зорилго нь илүү олон цонх, олон үйлдэлтэй систем бүтээх бус, **мэргэжлийн хүнд шаардлагатай зүйлээ бүрэн хийх боломж олгодог, илүү зүйлээр төвөг учруулахгүй мэргэжлийн багаж** бүтээх юм.

# 🚀 Энгийн интерфэйс, хурдан суралцах боломж [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%9A%80-%D1%8D%D0%BD%D0%B3%D0%B8%D0%B9%D0%BD-%D0%B8%D0%BD%D1%82%D0%B5%D1%80%D1%84%D1%8D%D0%B9%D1%81-%D1%85%D1%83%D1%80%D0%B4%D0%B0%D0%BD-%D1%81%D1%83%D1%80%D0%B0%D0%BB%D1%86%D0%B0%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6)

боломжтой.

> Өдөр тутмын бүртгэлийг энгийн байлгахын зэрэгцээ удирдлагын шийдвэр гаргалтад шаардлагатай тайлан, мэдээллийг хангалттай түвшинд гаргахыг зорьдог.

**Боломжтой.**

Dayansoft ERP-ийн бараг бүх цонх, модульд:

- 📋 цонх хооронд **Copy / Paste** хийх;
- 📤 Excel файл руу экспортлох;
- 📥 Excel файлаас импортлох

боломжтой.

[Copy, Paste болон Excel импорт, экспорт хийх заавар](https://docs.dayansoft.mn/erp/d015#excel-%D1%84%D0%B0%D0%B9%D0%BB%D0%B0%D0%B0%D1%81-%D0%BC%D1%8D%D0%B4%D1%8D%D1%8D%D0%BB%D1%8D%D0%BB-%D0%BE%D0%BB%D0%BD%D0%BE%D0%BE%D1%80-%D0%B8%D0%BC%D0%BF%D0%BE%D1%80%D1%82%D0%BB%D0%BE%D1%85)

Ингэснээр гар ажиллагаа болон цаг хугацааг хэмнэж, мэдээлэл гараар давхар оруулах үед үүсэх алдааг бууруулна.

> 💡 Өмнө нь өөр програм эсвэл Excel ашиглаж бүртгэл хөтөлж байсан байгууллага Dayansoft ERP рүү мэдээллээ шилжүүлэхэд мөн ашиглаж болно.

## 🔗 Dayansoft ERP бусад системтэй холбогдох боломжтой юу? [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%94%97-dayansoft-erp-%D0%B1%D1%83%D1%81%D0%B0%D0%B4-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D1%82%D1%8D%D0%B9-%D1%85%D0%BE%D0%BB%D0%B1%D0%BE%D0%B3%D0%B4%D0%BE%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6%D1%82%D0%BE%D0%B9-%D1%8E%D1%83)

**Боломжтой.**

Dayansoft ERP нь шаардлагатай тохиолдолд бусад системүүдтэй API болон интеграци холболтоор мэдээлэл солилцох боломжтой.

Одоогоор хийгдсэн интеграци болон холболтуудыг **[ЭНД](https://docs.dayansoft.mn/support/d187)** дарж харна уу.

> 💡 Dayansoft ERP-д өөрт байхгүй модуль, дэд системийн хэрэгцээг бусад мэргэшсэн системтэй интеграци хийх замаар шийдвэрлэх боломжтой.

## 🏦 Банкны дансны хуулгыг автоматаар татах боломжтой юу? [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%8F%A6-%D0%B1%D0%B0%D0%BD%D0%BA%D0%BD%D1%8B-%D0%B4%D0%B0%D0%BD%D1%81%D0%BD%D1%8B-%D1%85%D1%83%D1%83%D0%BB%D0%B3%D1%8B%D0%B3-%D0%B0%D0%B2%D1%82%D0%BE%D0%BC%D0%B0%D1%82%D0%B0%D0%B0%D1%80-%D1%82%D0%B0%D1%82%D0%B0%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6%D1%82%D0%BE%D0%B9-%D1%8E%D1%83)

**Боломжтой.**

Зарим банкуудтай шууд интеграци хийгдсэн бөгөөд Dayansoft ERP-ийн **Харилцахын жагсаалт** цонхноос дансны хуулгыг автоматаар татах боломжтой.

Холболт хийгдээгүй банкны хувьд Dayansoft ERP-ийн харилцахын гүйлгээ импортлох темплэйтийн дагуу **Excel файлаас импортлох** боломжтой.

## 🧮 Хууль, татвар, НДШ-ийн хувь хэмжээ өөрчлөгдөхөд яах вэ? [Anchor](https://docs.dayansoft.mn/erp/d012\#%F0%9F%A7%AE-%D1%85%D1%83%D1%83%D0%BB%D1%8C-%D1%82%D0%B0%D1%82%D0%B2%D0%B0%D1%80-%D0%BD%D0%B4%D1%88-%D0%B8%D0%B9%D0%BD-%D1%85%D1%83%D0%B2%D1%8C-%D1%85%D1%8D%D0%BC%D0%B6%D1%8D%D1%8D-%D3%A9%D3%A9%D1%80%D1%87%D0%BB%D3%A9%D0%B3%D0%B4%D3%A9%D1%85%D3%A9%D0%B4-%D1%8F%D0%B0%D1%85-%D0%B2%D1%8D)

Dayansoft ERP-ийн цалингийн модульд хууль, журам болон холбогдох хувь хэмжээ өөрчлөгдөх үед програм хөгжүүлэгч талаас шаардлагатай шинэчлэлтийг хийдэг.

Ингэснээр хэрэглэгч:

- томъёог гараар өөрчлөх;
- хувь хэмжээг өөрөө шинэчлэх;
- буруу томъёо үүсгэх

зэрэг эрсдэлээс сэргийлэгдэнэ.

Мөн хэрэглэгчид системийн шинэчлэлтийг нэгэн зэрэг авдаг тул хуучин хувилбар эсвэл хуучирсан томъёогоор цалин бодох эрсдэлийг бууруулна.

# ☁️ Dayansoft ERP cloud систем үү? [Anchor](https://docs.dayansoft.mn/erp/d012\#%E2%98%81%EF%B8%8F-dayansoft-erp-cloud-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC-%D2%AF%D2%AF)

Энд нэг чухал ялгааг ойлгох хэрэгтэй.

**Dayansoft ERP нь browser-оор шууд нэвтэрдэг web application биш.**

Dayansoft програм нь:

- 🖥️ Windows үйлдлийн системтэй төхөөрөмж дээр суурилуулна;
- 🔐 лиценз олгосон төхөөрөмжөөс ашиглана;
- 🌐 мэдээллийн бааз нь онлайн серверт байршдаг;
- 📡 интернеттэй үед лицензтэй төхөөрөмжөөс мэдээллийн бааздаа хандаж ажиллана.

Өөрөөр хэлбэл:

**Програм → Windows төхөөрөмж дээр суусан байна** **Мэдээллийн бааз → Cloud / онлайн серверт байрлаж болно**

Иймээс дурын компьютер дээр browser нээгээд шууд нэвтрэх систем биш юм.
