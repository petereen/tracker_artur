## 📌 Журнал бичилт гэж юу вэ? [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%93%8C-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB-%D0%B1%D0%B8%D1%87%D0%B8%D0%BB%D1%82-%D0%B3%D1%8D%D0%B6-%D1%8E%D1%83-%D0%B2%D1%8D)

**Журнал бичилт** цонхоор бусад модулиар бүртгэх боломжгүй буюу шууд журналын бичилтээр бүртгэх шаардлагатай ажил гүйлгээг бүртгэнэ.

Жишээлбэл:

- 🧾 Тохируулах бичилт (Жишээ нь, урьдчилж төлсөн зардал, түрээс, орлого гэх мэт.)
- 💰 Авлага үүсгэх
- 💳 Өглөг үүсгэх
- 🔄 Авлага, өглөг хаах
- 👥 Харилцагчийн тооцоо нэгтгэх
- 🧮 НӨАТ авлага, өглөг хаах
- 🏭 Дуусаагүй үйлдвэрлэлийн зардал нэгтгэх
- 📊 Бусад модулиар бүртгэх боломжгүй дансны журнал

Журнал бичилтийг:

- **нэг бүрчлэн гараар бүртгэх**
- **Журналын загвар ашиглан автомат үүсгэх**
- **Excel загвараар олноор импортлох**

боломжтой.

Мөн энэ цонхноос **Журналтай бүх баримтыг харах** чек сонгоод журнал холбосон бүх баримтын жагсаалтыг шүүж харах боломжтой.

![JournalEntryList](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntryList.png)

> 💡 **Зөвлөмж:** Давтамжтай хийгддэг ижил төрлийн журналын бичилттэй бол эхлээд **Санхүү бүртгэл → Журналын загвар** хэсэгт загвар үүсгээд ашиглаарай.

# ➕ 1\. Шинэ журнал бичилт үүсгэх [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%E2%9E%95-1-%D1%88%D0%B8%D0%BD%D1%8D-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB-%D0%B1%D0%B8%D1%87%D0%B8%D0%BB%D1%82-%D2%AF%D2%AF%D1%81%D0%B3%D1%8D%D1%85)

**Санхүү бүртгэл → Журнал бичилт** цонхноос **Шинэ (Ctrl+N)** товч дарна.

Журналын бичилтийг 2 аргаар үүсгэж болно.

### 📝 Арга 1\. Гараар бүртгэх [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%93%9D-%D0%B0%D1%80%D0%B3%D0%B0-1-%D0%B3%D0%B0%D1%80%D0%B0%D0%B0%D1%80-%D0%B1%D2%AF%D1%80%D1%82%D0%B3%D1%8D%D1%85)

**Нэмэх (Ctrl+Insert)** товч дарж мөр нэмээд:

1. Данс сонгоно.
2. Дебет, кредит дүн оруулна.
3. Шаардлагатай бол харилцагч, нэхэмжлэх, гэрээ, ажил зэрэг мэдээллийг сонгоно.
4. Багцыг тохируулна.
5. **Хадгалах** дарна.

![JournalEntryAdd](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntryAdd.png)

### ⚡ Арга 2\. Журналын загвар ашиглах [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%E2%9A%A1-%D0%B0%D1%80%D0%B3%D0%B0-2-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B7%D0%B0%D0%B3%D0%B2%D0%B0%D1%80-%D0%B0%D1%88%D0%B8%D0%B3%D0%BB%D0%B0%D1%85)

Хэрэв өмнө нь журналын загвар үүсгэсэн бол:

1. Журналын загвараа сонгоно.
2. **Холбох** товч дарна.
3. Систем журналын мөрүүдийг автоматаар үүсгэнэ.
4. Үүссэн бичилтийг шалгана.
5. **Хадгалах** дарна.

![JournalEntryUseTemplate](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntryUseTemplate.png)

# 📋 2\. Журналын толгой мэдээлэл [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%93%8B-2-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D1%82%D0%BE%D0%BB%D0%B3%D0%BE%D0%B9-%D0%BC%D1%8D%D0%B4%D1%8D%D1%8D%D0%BB%D1%8D%D0%BB)

| Талбар | Тайлбар |
| --- | --- |
| **Огноо** | Журнал бичилтийн огноо. |

# 🧾 3\. Журналын гүйлгээний мэдээлэл [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%A7%BE-3-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B3%D2%AF%D0%B9%D0%BB%D0%B3%D1%8D%D1%8D%D0%BD%D0%B8%D0%B9-%D0%BC%D1%8D%D0%B4%D1%8D%D1%8D%D0%BB%D1%8D%D0%BB)

| Талбар | Тайлбар |
| --- | --- |

| **Кредит дүн** | Кредитийн дүн. Валютын данс бол валютын дүнгээр оруулна. |
| **Кредит дүн ₮** | Кредитийн төгрөгөөрх дүн. Валютын дансанд валютын дүн × ханшаар тооцогдоно. |
| **Мөнгөн гүйлгээ** | Мөнгөн хөрөнгийн данстай харьцсан гүйлгээг мөнгөн гүйлгээний тайланд ангилахад ашиглана. |
| **Харилцагч код** | Тухайн гүйлгээтэй холбоотой харилцагчийг сонгоно. |
| **Харилцагч нэр** | Сонгосон харилцагчийн нэрийг харуулна. |
| **Тооцоо №** | Өмнө тооцоо үүссэн баримтыг сонгох эсвэл гараас тооцооны дугаарыг оруулж болно. Сонгосноор тухайн тооцоог хаах боломжтой. |
| **Тооцоо хариуцагч** | Тухайн тооцоог хариуцаж буй ажилтанг сонгоно. |
| **Гэрээ код** | Гүйлгээтэй холбоотой гэрээг сонгоно. Дараа нь гэрээгээр тайлан шүүж болно. |
| **Ажил код** | Гүйлгээтэй холбоотой ажлыг сонгоно. Дараа нь ажлаар тайлан шүүж болно. |
| **Төлбөрийн хуваарь** | Гүйлгээний төлбөрийн хуваарийг сонгоно. |
| **Reference** | Эх сурвалж баримтын лавлах дугаар. |
| **Дугаар** | Эх сурвалж баримтын дугаар. |
| **Утга** | Гүйлгээний утга, тайлбар. |
| **Утга /EN/** | Гүйлгээний утгын орчуулга. |

# ⚖️ 4\. Журнал хадгалах үеийн шалгалт [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%E2%9A%96%EF%B8%8F-4-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB-%D1%85%D0%B0%D0%B4%D0%B3%D0%B0%D0%BB%D0%B0%D1%85-%D2%AF%D0%B5%D0%B8%D0%B9%D0%BD-%D1%88%D0%B0%D0%BB%D0%B3%D0%B0%D0%BB%D1%82)

Журнал хадгалах үед систем бичилтийн зөв эсэхийг автоматаар шалгана.

## 4.1 Дебет, кредит дүн тэнцүү байх [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#4-1-%D0%B4%D0%B5%D0%B1%D0%B5%D1%82-%D0%BA%D1%80%D0%B5%D0%B4%D0%B8%D1%82-%D0%B4%D2%AF%D0%BD-%D1%82%D1%8D%D0%BD%D1%86%D2%AF%D2%AF-%D0%B1%D0%B0%D0%B9%D1%85)

Нэг **Багц** доторх дебетийн нийт дүн кредитийн нийт дүнтэй тэнцүү байх шаардлагатай.

Дүн зөрсөн тохиолдолд систем:

> ❌ **“1-р гүйлгээний багцын дебет кредитийн дүн тэнцэхгүй байна!”**

гэсэн алдаа харуулна.

![JournalEntrySaveValidation1](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntrySaveValidation1.png)

Дээрх жишээ дээр Дебет дүн 45,000 Кредит дүн 50,000 зөрүү 5,000 учраас хадгалагдахгүй.

### 🔎 Яах вэ? [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%94%8E-%D1%8F%D0%B0%D1%85-%D0%B2%D1%8D)

Тухайн багцын:

- Дебетийн мөрүүд
- Кредитийн мөрүүд
- Нийт дүн
- Валютын ханш

зэргийг шалгаад дүнг тэнцүүлж хадгална.

# 🔀 5\. Нэг багцад олон дебет – олон кредит бичихгүй [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%94%80-5-%D0%BD%D1%8D%D0%B3-%D0%B1%D0%B0%D0%B3%D1%86%D0%B0%D0%B4-%D0%BE%D0%BB%D0%BE%D0%BD-%D0%B4%D0%B5%D0%B1%D0%B5%D1%82-%E2%80%93-%D0%BE%D0%BB%D0%BE%D0%BD-%D0%BA%D1%80%D0%B5%D0%B4%D0%B8%D1%82-%D0%B1%D0%B8%D1%87%D0%B8%D1%85%D0%B3%D2%AF%D0%B9)

Dayansoft ERP системд нэг **Багц** дотор:

> **Олон дебет ↔ олон кредит**

харьцаатай бичилт хийхийг зөвшөөрдөггүй.

Хэрэв ийм харьцаа үүсвэл:

> ❌ **1-р гүйлгээний багцад олон дебет олон кредитийн харьцаа үүссэн байна!Багц багананд 2 тусдаа багц болгож давхар бичилт болгоно уу!**

гэсэн алдаа гарна.

## 💡 Яагаад? [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%92%A1-%D1%8F%D0%B0%D0%B3%D0%B0%D0%B0%D0%B4)

Нэг багцад олон дебет, олон кредит зөвшөөрвөл тухайн данс **яг аль данстай, ямар дүнгээр харьцсан** нь тодорхойгүй, тодорхойлох боломжгүй болно.

Ингэснээр **Ерөнхий журналын дэлгэрэнгүй** тайланг зөв гаргах боломжгүй.

# 🔄 6\. Олон дебет – олон кредитийг хэрхэн салгах вэ? [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%94%84-6-%D0%BE%D0%BB%D0%BE%D0%BD-%D0%B4%D0%B5%D0%B1%D0%B5%D1%82-%E2%80%93-%D0%BE%D0%BB%D0%BE%D0%BD-%D0%BA%D1%80%D0%B5%D0%B4%D0%B8%D1%82%D0%B8%D0%B9%D0%B3-%D1%85%D1%8D%D1%80%D1%85%D1%8D%D0%BD-%D1%81%D0%B0%D0%BB%D0%B3%D0%B0%D1%85-%D0%B2%D1%8D)

Олон дебет, олон кредитийн харьцаатай гүйлгээг **дамжих данс ашиглан тусдаа багц** болгон бүртгэнэ.

### Жишээ [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%D0%B6%D0%B8%D1%88%D1%8D%D1%8D)

Борлуулалтын нэг гүйлгээнд:

**Дебет:**

- Голомт банк
- Касс дахь мөнгө

**Кредит:**

- Борлуулалтын орлого
- НӨАТ өглөг

гэсэн 2 × 2 харьцаа үүссэн гэж үзье.

![JournalEntrySaveValidation1](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntrySaveValidation1.png)

Үүнийг нэг багцад хийхийн оронд дараах байдлаар **Борлуулалтын тооцоо** зэрэг дамжих данс ашиглан 2 тусдаа багц болгон салгана.

![JournalEntrySaveValidation2](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntrySaveValidation2.png)

> 📌 Үүнийг **давхар бичилт** хэлбэрээр зохион байгуулснаар данс хоорондын харьцаа тодорхой болж, дэлгэрэнгүй журналын тайлан зөв гарна.

# 🖱️ 7\. Баруун товчны үйлдлүүд [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%96%B1%EF%B8%8F-7-%D0%B1%D0%B0%D1%80%D1%83%D1%83%D0%BD-%D1%82%D0%BE%D0%B2%D1%87%D0%BD%D1%8B-%D2%AF%D0%B9%D0%BB%D0%B4%D0%BB%D2%AF%D2%AF%D0%B4)

Журнал бичилтийн мөр дээр **хулганы баруун товч** дарж дараах үйлдлүүдийг ашиглаж болно.

| Үйлдэл | Зориулалт |
| --- | --- |
| 🧾 **НӨАТ салгах** | НӨАТ-тай дүнгээс НӨАТ-ыг салгаж бичилт үүсгэнэ. |
| 🔄 **Буцааж бичих (Reversing)** | Одоогийн бичилтийн дебет, кредитийг эсрэгээр нь бичиж буцаах журнал үүсгэнэ. |
| 🔄 **Буцааж бичих (дансгүй)** | Дансны тохиргоогүйгээр буцаах бичилт үүсгэхэд ашиглана. |
| 🔎 **Гүйлгээ харах** | Сонгосон дансаар хийсэн гүйлгээний жагсаалт руу шилжинэ. |
| 👥 **Тооцоо харах** | Сонгосон харилцагчийн тооцоо руу шилжинэ. |
| 👥 **Харилцагч харах** | Сонгосон харилцагчийн бүртгэл рүү шилжинэ. |
| 🏭 **Ажлаар задлах** | Өмнөх гүйлгээг ажил тус бүрээр хөтөлсөн бол ажил тус бүрээр дүнг автомат задлана. |

![JournalEntryRowAction](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/10.finance/23.d051/JournalEntryRowAction.png)

### 🏭 Ажлаар задлах жишээ [Anchor](https://docs.dayansoft.mn/erp/finance/d051\#%F0%9F%8F%AD-%D0%B0%D0%B6%D0%BB%D0%B0%D0%B0%D1%80-%D0%B7%D0%B0%D0%B4%D0%BB%D0%B0%D1%85-%D0%B6%D0%B8%D1%88%D1%8D%D1%8D)

Үйлдвэрлэлийн байгууллага:

- ШМЗ
- ШХЗ
