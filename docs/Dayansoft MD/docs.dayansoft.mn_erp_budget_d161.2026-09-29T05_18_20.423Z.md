# 📊 Төсөв модуль [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%F0%9F%93%8A-%D1%82%D3%A9%D1%81%D3%A9%D0%B2-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D1%8C)

## 📌 Модулийн тухай [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%F0%9F%93%8C-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D0%B8%D0%B9%D0%BD-%D1%82%D1%83%D1%85%D0%B0%D0%B9)

Энэ модуль нь байгууллагын бизнесийн үйл ажиллагааг **төсөвлөн төлөвлөх**, бодит гүйцэтгэлийг төсөвтэй харьцуулах, төлөвлөгөөний биелэлтийг хэмжих, алдаа дутагдал болон амжилтыг **тоон үзүүлэлтээр хянах** боломжийг бүрдүүлнэ.

Өөрөөр хэлбэл:

> **🎯 Төлөвлөгөө → 📊 Төсөв → 📈 Бодит гүйцэтгэл → 🔎 Харьцуулалт → 🧠 Шийдвэр**

гэсэн удирдлагын мөчлөгийг нэг системд хөтөлнө.

Төсвийг:

- 📅 Сар
- 📆 Улирал
- 🗓️ Жил
- ⏱️ Дурын хугацаа
- 🏗️ Төслөөр
- 🔢 Төсвийн хэд хэдэн хувилбараар

үүсгэж, хадгалж, харьцуулан шинжлэх боломжтой.

# 🧭 Модультай ажиллах үндсэн дараалал [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%F0%9F%A7%AD-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D0%B9-%D0%B0%D0%B6%D0%B8%D0%BB%D0%BB%D0%B0%D1%85-%D2%AF%D0%BD%D0%B4%D1%81%D1%8D%D0%BD-%D0%B4%D0%B0%D1%80%D0%B0%D0%B0%D0%BB%D0%B0%D0%BB)

- ↓
- **② 📁 Төсөвт дансны бүлэг үүсгэх**
- ↓
- **③ 💳 Төсөвт данс үүсгэх**
- ↓
- **④ 🎯 Төсөв боловсруулах**
- ↓
- **⑤ 📈 Бодит гүйцэтгэлтэй харьцуулах**
- ↓

# 📚 1\. Дансны төлөвлөгөөг зөв зохион байгуулах [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%F0%9F%93%9A-1-%D0%B4%D0%B0%D0%BD%D1%81%D0%BD%D1%8B-%D1%82%D3%A9%D0%BB%D3%A9%D0%B2%D0%BB%D3%A9%D0%B3%D3%A9%D3%A9%D0%B3-%D0%B7%D3%A9%D0%B2-%D0%B7%D0%BE%D1%85%D0%B8%D0%BE%D0%BD-%D0%B1%D0%B0%D0%B9%D0%B3%D1%83%D1%83%D0%BB%D0%B0%D1%85)

Төсөвлөх болон бодит гүйцэтгэлийг хэмжихэд хамгийн чухал суурь мэдээлэл бол **дансны төлөвлөгөө** юм.

Иймээс:

- Орлогын данс
- Зардлын данс
- Борлуулалтын данс
- Үйл ажиллагааны зардал
- Цалин
- Түрээс
- Маркетинг
- Тээвэр
- Бусад зардал

зэрэг байгууллагын бизнесийг хэмжихэд шаардлагатай дансуудыг **оновчтой, ойлгомжтой бүтэцтэй** үүсгэнэ.

> 🎯 **Зөв төсөв = Зөв дансны бүтэц \+ Зөв төлөвлөгөө \+ Зөв бүртгэл**

Хэт ерөнхий дансны бүтэцтэй бол төсөвлөлт хийсэн ч дараа нь ямар үйл ажиллагаа төлөвлөгөөнөөс зөрсөн болохыг нарийвчлан харахад хүндрэлтэй.

# 📁 2\. Төсөвт дансны бүлэг [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%F0%9F%93%81-2-%D1%82%D3%A9%D1%81%D3%A9%D0%B2%D1%82-%D0%B4%D0%B0%D0%BD%D1%81%D0%BD%D1%8B-%D0%B1%D2%AF%D0%BB%D1%8D%D0%B3)

Төсөвт дансны бүлэг нь санхүүгийн дансны бүлгээс өөр байж болно.

Харин төсөвт дансны бүтэц:

📊 **Төсөвлөх, шинжлэх, удирдах** зорилгоор ашиглагдана.

# 🧮 Ашгийг төсвөөр харах [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%F0%9F%A7%AE-%D0%B0%D1%88%D0%B3%D0%B8%D0%B9%D0%B3-%D1%82%D3%A9%D1%81%D0%B2%D3%A9%D3%A9%D1%80-%D1%85%D0%B0%D1%80%D0%B0%D1%85)

Орлого эерэг, зардал сөрөг учраас:

> **🎯 Ашиг = Орлого \+ Зардал**

гэсэн логикоор нийт үр дүн гарна.

Жишээ:

📈 Орлого = **500 сая**

📉 Зардал = **-350 сая**

→ 📊 Төсөвлөсөн ашиг = **150 сая**

Энэ арга нь төсөв анализ дээр орлого, зардлын нийлбэрийг ашигтай уялдуулан харуулахад тохиромжтой.

### ⭐ Санамж [Anchor](https://docs.dayansoft.mn/erp/budget/d161\#%E2%AD%90-%D1%81%D0%B0%D0%BD%D0%B0%D0%BC%D0%B6)

**Төсөв модуль** нь зөвхөн “ирэх жилийн хэдэн төгрөгийн орлого, зардалтай байх вэ?” гэж тоо оруулах зориулалттай биш. Гол үнэ цэнэ нь:

> **“Бид юу төлөвлөсөн бэ?” → “Одоогоор хаана явж байна вэ?” → “Төлөвлөгөөнөөс яагаад зөрөв?” → “Юу хийх хэрэгтэй вэ?”**

гэсэн 4 асуултад тоон мэдээллээр хариу өгөхөд оршино.
