# 🔗 Dayansoft системийн интеграци, API холболт [Anchor](https://docs.dayansoft.mn/support/d187\#%F0%9F%94%97-dayansoft-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B8%D0%B9%D0%BD-%D0%B8%D0%BD%D1%82%D0%B5%D0%B3%D1%80%D0%B0%D1%86%D0%B8-api-%D1%85%D0%BE%D0%BB%D0%B1%D0%BE%D0%BB%D1%82)

Dayansoft ХХК нь бүх төрлийн системийг өөрсдөө шинээр хөгжүүлэхээс илүүтэйгээр **тухайн систем, модулийн чиглэлээр мэргэшсэн бусад системүүдтэй интеграци хийх** стратегийг баримталдаг.

Гэхдээ зах зээл дээрх бүх системтэй холболт хийх боломжгүй тул **харилцагчдын нийтлэг бөгөөд зайлшгүй хэрэгцээ шаардлагад үндэслэн** шаардлагатай системүүдтэй интеграци холболтыг хийдэг.

> 💡 **Зөвлөмж**
> Танай байгууллага ашиглаж буй системтэй Dayansoft холбогдох эсэхийг урьдчилан тодруулах шаардлагатай бол тухайн системийн нэр, ямар мэдээлэл солилцох шаардлагатай байгаа талаар Даянсофт ХХК-д мэдээлнэ үү.

**Нэхэмжлэх авах бол [ЭНД](https://dayansoft.bitrix24.site/getProductService/) дарж форм бөглөнө үү.**

Dayansoft ERP-тэй НӨАТУС системийн дараах холболтууд хийгдсэн.

- Татварын системээс ААН болон бизнес эрхлэгч иргэний регистрээр хуулийн этгээдийн албан ёсны нэр, ТТД, НӨАТ, НХАТ суутган төлөгч эсэх тохиргоог автоматаар дуудах.
