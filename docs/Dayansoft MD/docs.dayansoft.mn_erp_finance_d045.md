## 📌 Модулийн тухай [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%F0%9F%93%8C-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D0%B8%D0%B9%D0%BD-%D1%82%D1%83%D1%85%D0%B0%D0%B9)

**Санхүү бүртгэл** модуль нь байгууллагын санхүү, нягтлан бодох бүртгэлийн бүх ажил гүйлгээг бүртгэх, хянах, тохируулах, санхүүгийн тайлан гаргах үндсэн үүрэгтэй.

Уг модульд байгууллагын өдөр тутмын санхүүгийн бүртгэлээс эхлээд тайлант үеийн хаалт, дансны ханшийн тэгшитгэл, ерөнхий журнал, шалгах баланс, санхүүгийн тайлан болон өглөг, авлагын тооцоог хөтлөх боломжтой.

### 🧩 Модулийн үндсэн хэсгүүд [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%F0%9F%A7%A9-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D0%B8%D0%B9%D0%BD-%D2%AF%D0%BD%D0%B4%D1%81%D1%8D%D0%BD-%D1%85%D1%8D%D1%81%D0%B3%D2%AF%D2%AF%D0%B4)

- 📒 **Санхүү бүртгэл** — дансны төлөвлөгөө, тайлант үе, эхний үлдэгдэл, журнал бичилт, ханшийн тэгшитгэл, тайлант үеийн хаалт.
- 🤝 **Өглөг, авлага** — харилцагч, ажилтан болон бусад тооцоо хариуцагчийн өглөг, авлагын тооцоо, тооцооны ханш тэгшитгэл.
- 📊 **Тайлан, шинжилгээ** — байгууллагын санхүүгийн байдлыг данс, салбар, бизнес төв, гэрээ болон бусад үзүүлэлтээр шинжлэх, тайлагнах.

## 📒 Санхүү бүртгэл, ерөнхий дэвтэр [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%F0%9F%93%92-%D1%81%D0%B0%D0%BD%D1%85%D2%AF%D2%AF-%D0%B1%D2%AF%D1%80%D1%82%D0%B3%D1%8D%D0%BB-%D0%B5%D1%80%D3%A9%D0%BD%D1%85%D0%B8%D0%B9-%D0%B4%D1%8D%D0%B2%D1%82%D1%8D%D1%80)

**Санхүү бүртгэл, ерөнхий дэвтэр** хэсэгт дараах үндсэн үйлдлүүдийг хийх боломжтой.

- 🏦 Дансны код, дансны төлөвлөгөө үүсгэх, тохируулах
- 📅 Тайлант үе болон эхний үлдэгдлийн огноо тохируулах
- 🔒 Тайлант үе хаах
- 🔓 Хаасан тайлант үеийг буцааж нээх
- 💱 Дансны ханшийн тэгшитгэл хийх
- 📒 Туслах журнал хөтөлдөггүй дансаар журнал бичилт хийх
- 🛠️ Тохируулах бичилт хийх
- 🔄 Давтамжтай журналын бичилтийн загвар үүсгэх
- 🧮 Журналын загварт томъёо угсрах
- 👁️ Байгууллагын хэмжээнд хийгдсэн бүх ажил гүйлгээний журналын бичилтийг харах
- ✏️ Журналын бичилтийг засах
- 🗑️ Журналын бичилтийг устгах
- 🕵️ Гүйлгээ зассан, устгасан түүхийг баримтын түвшинд харах, шүүх
- ⚖️ Шалгах балансаар бүх дансны эхний үлдэгдэл, эцсийн үлдэгдэл, өөрчлөлтийг хянах
- 📊 Санхүүгийн тайлангуудыг харах

# ⚙️ Эхлэхийн өмнө анхаарах зүйлс [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%E2%9A%99%EF%B8%8F-%D1%8D%D1%85%D0%BB%D1%8D%D1%85%D0%B8%D0%B9%D0%BD-%D3%A9%D0%BC%D0%BD%D3%A9-%D0%B0%D0%BD%D1%85%D0%B0%D0%B0%D1%80%D0%B0%D1%85-%D0%B7%D2%AF%D0%B9%D0%BB%D1%81)

Санхүү бүртгэлийг зөв хөтлөхийн тулд байгууллагын онцлогт тохируулан **тайлант үе, дансны төлөвлөгөө, эхний үлдэгдэл, мөнгөн хөрөнгө болон өглөг, авлагын тохиргоог** зөв хийх шаардлагатай.

## 📅 Тайлант үе [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%F0%9F%93%85-%D1%82%D0%B0%D0%B9%D0%BB%D0%B0%D0%BD%D1%82-%D2%AF%D0%B5)

Байгууллагын үйл ажиллагааны онцлогоос хамаарч тайлант үеэ **сар, улирал эсвэл бусад тохирох хугацаагаар** хөтлөх эсэхээ дотооддоо шийдсэн байна.

Хуанлийн хугацаагаар тайлант үе дуусаж, тайлан балансаа гаргасны дараа тайлант үеийг тогтмол хааж байхыг зөвлөж байна.

🔒 Тайлант үе хааснаар:

- 🛡️ Өмнөх үеийн ажил гүйлгээ санамсаргүй засагдахаас
- 🗑️ Ажил гүйлгээ санамсаргүй устахаас
- ➕ Өмнөх тайлант үед шинээр гүйлгээ бүртгэгдэхээс

сэргийлнэ.

## 🏦 Дансны төлөвлөгөө [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%F0%9F%8F%A6-%D0%B4%D0%B0%D0%BD%D1%81%D0%BD%D1%8B-%D1%82%D3%A9%D0%BB%D3%A9%D0%B2%D0%BB%D3%A9%D0%B3%D3%A9%D3%A9)

- 🗂️ Дансны төрөл
- 📊 Санхүүгийн тайлангийн үзүүлэлт
- 🧾 Татварын үзүүлэлт
- 🏦 Үндсэн данс
- 👨‍💼 Нягтлан
- 👨‍🔧 Нярав
- 💱 Валют
- ⚙️ Бусад шаардлагатай нэмэлт тохиргоо

⚠️ **Анхаарах:** Буруу тохиргоо хийсэн тохиолдолд тайлан буруу гарах эрсдэлтэй.

### 💵 Мөнгөн хөрөнгийн данс [Anchor](https://docs.dayansoft.mn/erp/finance/d045\#%F0%9F%92%B5-%D0%BC%D3%A9%D0%BD%D0%B3%D3%A9%D0%BD-%D1%85%D3%A9%D1%80%D3%A9%D0%BD%D0%B3%D0%B8%D0%B9%D0%BD-%D0%B4%D0%B0%D0%BD%D1%81)

Жишээлбэл, борлуулалтаар авлага үүсгэх, худалдан авалтаар өглөг үүсгэх, төлбөрөөр өглөг болон авлага хаах зэрэг тооцооны хөдөлгөөнийг холбогдох журнал бичилтээр бүртгэнэ.
