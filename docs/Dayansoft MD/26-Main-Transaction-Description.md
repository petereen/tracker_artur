## Гүйлгээний утга гэж юу вэ? [Anchor](https://docs.dayansoft.mn/erp/main/d030\#%D0%B3%D2%AF%D0%B9%D0%BB%D0%B3%D1%8D%D1%8D%D0%BD%D0%B8%D0%B9-%D1%83%D1%82%D0%B3%D0%B0-%D0%B3%D1%8D%D0%B6-%D1%8E%D1%83-%D0%B2%D1%8D)

Энэ цонхонд баримт, гүйлгээний **утга, зориулалт, тайлбар** зэрэг мэдээллийг лавлах хэлбэрээр урьдчилан бүртгэнэ.

Гүйлгээний утгыг урьдчилан бүртгэснээр баримт шивэх үед нэг ижил утгыг дахин дахин гараас бичих шаардлагагүй болж, **бүртгэсэн утгаас сонгон оруулах** боломжтой болно.

![TransactionDescReceipt](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/09.main/12.d030/TransactionDescReceipt.png)

Жишээлбэл, байгууллага сар бүр ижил төрлийн гүйлгээ хийдэг бол:

- Түрээсийн төлбөр
- Цалингийн төлбөр
- Тээврийн зардал
- Бараа материалын төлбөр

зэрэг утгуудыг урьдчилан бүртгэж болно.

> **Зөвлөмж:** Гүйлгээний утгыг заавал урьдчилан бүртгэх шаардлагагүй. Баримт шивэх үедээ гараас шууд оруулж болно. Харин ижил төрлийн гүйлгээний утгыг хэрэглэгч бүр өөр өөрөөр бичих, нэг мэдээллийг давтан шивэх зэрэг гар ажиллагааг багасгахын тулд түгээмэл ашигладаг утгуудаа лавлах хэлбэрээр бүртгэхийг зөвлөж байна.

# Зөвлөмж [Anchor](https://docs.dayansoft.mn/erp/main/d030\#%D0%B7%D3%A9%D0%B2%D0%BB%D3%A9%D0%BC%D0%B6)

Гүйлгээний утгыг бүртгэхдээ байгууллагад **давтамжтай ашиглагддаг, утга агуулгын хувьд ижил төрлийн гүйлгээнүүдэд** ашиглах нь тохиромжтой.

Ингэснээр:

**Гүйлгээний утга бүртгэх → Баримт шивэх үед сонгох → Давтан шивэх ажиллагааг багасгах**

зарчмаар ажиллана.

> **Гол санаа:** Гүйлгээний утгын лавлахыг зөв ашигласнаар ижил төрлийн гүйлгээний утгыг хэрэглэгч бүр өөр өөрөөр бичихээс сэргийлж, **өгөгдлийн нэг стандартыг хадгалан, баримт шивэлтийг хурдасгах** боломжтой.
