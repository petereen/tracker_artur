## Хэмжих нэгж гэж юу вэ? [Anchor](https://docs.dayansoft.mn/erp/main/d034\#%D1%85%D1%8D%D0%BC%D0%B6%D0%B8%D1%85-%D0%BD%D1%8D%D0%B3%D0%B6-%D0%B3%D1%8D%D0%B6-%D1%8E%D1%83-%D0%B2%D1%8D)

Энэ цонхонд ERP системийн бүртгэлд ашиглах **хэмжих нэгжийн лавлах мэдээллийг** бүртгэнэ.

Dayansoft ERP системд **бараа материал болон үндсэн хөрөнгийг нэг үндсэн хэмжих нэгжээр** бүртгэн хөтөлнө.

Харин худалдан авалт болон зарлагын гүйлгээнд **савлагааны хэмжээ** тохируулснаар тухайн барааг өөр нэгжээр гүйлгээ хийх боломжтой.

### Жишээ [Anchor](https://docs.dayansoft.mn/erp/main/d034\#%D0%B6%D0%B8%D1%88%D1%8D%D1%8D)

Барааг үндсэн бүртгэл дээр **ширхэгээр** бүртгэдэг боловч худалдан авалтыг **хайрцагаар** хийдэг бол савлагааны хэмжээг тохируулж, худалдан авалт болон зарлагын гүйлгээг хайрцагаар бүртгэх боломжтой.

Хайрцагтай болон задгай нэгжтэй барааны хувьд:

- Багцын тоогоор бүртгэх
- Хайрцаг болон задгай нэгжийг тусдаа бараа код болгон бүртгэх

аль хувилбар тохиромжтойг харилцагч байгууллагын үйл ажиллагаа, бүртгэлийн хэрэгцээнд үндэслэн урьдчилан тохиролцож сонгохыг зөвлөж байна.

# 1\. Системд бэлэн байгаа хэмжих нэгж [Anchor](https://docs.dayansoft.mn/erp/main/d034\#1-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B4-%D0%B1%D1%8D%D0%BB%D1%8D%D0%BD-%D0%B1%D0%B0%D0%B9%D0%B3%D0%B0%D0%B0-%D1%85%D1%8D%D0%BC%D0%B6%D0%B8%D1%85-%D0%BD%D1%8D%D0%B3%D0%B6)

Dayansoft ERP системийг анх суурилуулах үед Монгол Улсад мөрдөгдөж буй хэмжих нэгжүүдийн жагсаалтыг системд оруулсан байдаг.

**2019 оны 12 дугаар сараас хойш** суурилуулалт хийлгэсэн байгууллагуудад уг жагсаалт нэвтэрсэн бөгөөд жагсаалтыг **ebarimt.mn** сайтаас авсан.

Иймээс системд шаардлагатай хэмжих нэгж бүртгэгдсэн бол дахин шинээр үүсгэх шаардлагагүй.

* * *

# 3\. Хэмжих нэгжийн мэдээлэл бүртгэх [Anchor](https://docs.dayansoft.mn/erp/main/d034\#3-%D1%85%D1%8D%D0%BC%D0%B6%D0%B8%D1%85-%D0%BD%D1%8D%D0%B3%D0%B6%D0%B8%D0%B9%D0%BD-%D0%BC%D1%8D%D0%B4%D1%8D%D1%8D%D0%BB%D1%8D%D0%BB-%D0%B1%D2%AF%D1%80%D1%82%D0%B3%D1%8D%D1%85)

### Код [Anchor](https://docs.dayansoft.mn/erp/main/d034\#%D0%BA%D0%BE%D0%B4)

Хэмжих нэгжийн кодыг оруулна.

Дурын код өгөх боломжтой бөгөөд **товч, ойлгомжтой код** ашиглах нь тохиромжтой.

### Нэр [Anchor](https://docs.dayansoft.mn/erp/main/d034\#%D0%BD%D1%8D%D1%80)

Хэмжих нэгжийн нэрийг оруулна.

Жишээлбэл тухайн байгууллагын ашигладаг хэмжих нэгжийн нэрийг оруулна.

### Дараалал [Anchor](https://docs.dayansoft.mn/erp/main/d034\#%D0%B4%D0%B0%D1%80%D0%B0%D0%B0%D0%BB%D0%B0%D0%BB)

Бусад цонхонд хэмжих нэгжийн жагсаалт **ямар дарааллаар харагдахыг** тохируулна.

### Default [Anchor](https://docs.dayansoft.mn/erp/main/d034\#default)

Бараа шинээр кодлох үед **анхдагч байдлаар санал болгох хэмжих нэгжийг** сонгоно.

Жишээлбэл, байгууллага бараа материалаа ихэвчлэн ширхэгээр бүртгэдэг бол **ширхэг** хэмжих нэгжийг Default болгож тохируулж болно.

# Зөвлөмж [Anchor](https://docs.dayansoft.mn/erp/main/d034\#%D0%B7%D3%A9%D0%B2%D0%BB%D3%A9%D0%BC%D0%B6)

Хэмжих нэгжийг шинээр бүртгэхээс өмнө тухайн нэгж системд бүртгэлтэй эсэхийг шалгаарай.

Мөн бараа материалын бүртгэл хийхээс өмнө тухайн барааг **ямар үндсэн хэмжих нэгжээр бүртгэх**, худалдан авалт болон зарлагыг **өөр савлагааны нэгжээр бүртгэх шаардлагатай эсэхийг** тодорхойлох нь зүйтэй.

> **Гол санаа:** Dayansoft ERP системд бараа материал, үндсэн хөрөнгийг нэг үндсэн хэмжих нэгжээр бүртгэж, шаардлагатай тохиолдолд савлагааны хэмжээг ашиглан худалдан авалт, зарлагыг өөр нэгжээр бүртгэх боломжтой.
