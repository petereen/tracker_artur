## 💼 Үйлчилгээний нөхцөл ба Төлбөртэй үйлчилгээний жагсаалт [Anchor](https://docs.dayansoft.mn/support/d227\#%F0%9F%92%BC-%D2%AF%D0%B9%D0%BB%D1%87%D0%B8%D0%BB%D0%B3%D1%8D%D1%8D%D0%BD%D0%B8%D0%B9-%D0%BD%D3%A9%D1%85%D1%86%D3%A9%D0%BB-%D0%B1%D0%B0-%D1%82%D3%A9%D0%BB%D0%B1%D3%A9%D1%80%D1%82%D1%8D%D0%B9-%D2%AF%D0%B9%D0%BB%D1%87%D0%B8%D0%BB%D0%B3%D1%8D%D1%8D%D0%BD%D0%B8%D0%B9-%D0%B6%D0%B0%D0%B3%D1%81%D0%B0%D0%B0%D0%BB%D1%82)

Даянсофт ХХК нь зөвхөн өөрсдийн хөгжүүлсэн бүтээгдэхүүн, тэдгээртэй холбоотой нэмэлт үйлчилгээг харилцагч байгууллагууддаа үзүүлдэг. Үйлчилгээг **100% онлайнаар, зайнаас** хийж гүйцэтгэх бөгөөд шаардагдах хүн/цагийг тооцон хоёр тал тохиролцсоны үндсэн дээр нэхэмжлэх илгээн гүйцэтгэдэг.

### ✅ Төлбөртэй үзүүлэх боломжтой үйлчилгээнүүд: [Anchor](https://docs.dayansoft.mn/support/d227\#%E2%9C%85-%D1%82%D3%A9%D0%BB%D0%B1%D3%A9%D1%80%D1%82%D1%8D%D0%B9-%D2%AF%D0%B7%D2%AF%D2%AF%D0%BB%D1%8D%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6%D1%82%D0%BE%D0%B9-%D2%AF%D0%B9%D0%BB%D1%87%D0%B8%D0%BB%D0%B3%D1%8D%D1%8D%D0%BD%D2%AF%D2%AF%D0%B4)

- Dayansoft POS шилжүүлэн суулгах, дахин суулгах
- Dayansoft ERP системээс E-Barimt илгээх тохиргоо хийх
- Мэдээллийн бааз өндөрлөх / Шинэ баазаар эхлэх
- Регистр, ААН солих, шилжүүлэх
- Анхан шатны баримт болон гэрээний загвар зурж, програмаас хэвлэх боломжтой болгох
- API сервис хөгжүүлж өгөх
- Бусад систем, програмуудтай интеграци холболт хийх
- Дата, мэдээлэл, ажил гүйлгээтэй холбоотой үйлчилгээнүүд
  - Бааз хооронд гүйлгээ хуулах (Data migration)
  - Бааз сэргээх (Restore archive)
  - Дата мэдээлэл олноор оруулах, өөрчлөх, устгах (Data insert, update, delete)

### ❌ Үзүүлэх боломжгүй (Татгалзах) үйлчилгээнүүд: [Anchor](https://docs.dayansoft.mn/support/d227\#%E2%9D%8C-%D2%AF%D0%B7%D2%AF%D2%AF%D0%BB%D1%8D%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6%D0%B3%D2%AF%D0%B9-%D1%82%D0%B0%D1%82%D0%B3%D0%B0%D0%BB%D0%B7%D0%B0%D1%85-%D2%AF%D0%B9%D0%BB%D1%87%D0%B8%D0%BB%D0%B3%D1%8D%D1%8D%D0%BD%D2%AF%D2%AF%D0%B4)

Даянсофт ХХК нь өөрсдийн програм хангамжаас гадуурх дараах тоног төхөөрөмж болон компьютерын тохиргооны ажлуудыг Даянсофт ХХК **хариуцахгүй**:

1. **Принтерийн тохиргоо:**
   - USB болон Сүлжээний принтер компьютер дээр таниулах
2. **Компьютерын үйлчилгээ:**
   - Компьютер форматлах, үйлдлийн систем суулгах
3. **Гуравдагч програм:**
   - Даянсофтын бүтээгдэхүүнээс бусад програм хангамжийг суулгах, тохируулах. MS Office, Email, Message гэх мэт.
