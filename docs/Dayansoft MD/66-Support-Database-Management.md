# Алдааны мессежүүд [Anchor](https://docs.dayansoft.mn/support/d195\#%D0%B0%D0%BB%D0%B4%D0%B0%D0%B0%D0%BD%D1%8B-%D0%BC%D0%B5%D1%81%D1%81%D0%B5%D0%B6%D2%AF%D2%AF%D0%B4)

Програм хөгжүүлэлтийн явцад товч, үйлдэл бүрийг кодчилж, програмын зүгээс хэрэглэгчид өгч буй мессеж, анхааруулгыг аль болох **тухайн орны хэлээр, ойлгомжтой байдлаар** харуулах шаардлагатай.

Гэхдээ програм ашиглах явцад гарч болох бүх нөхцөл, кейсийг урьдчилан тооцох боломжгүй байдаг. Үүний улмаас зарим тохиолдолд **орчуулагдаагүй эсвэл техникийн шинжтэй англи хэл дээрх алдааны мессеж** хэрэглэгчид харагдаж болно.

Ийм алдаа гарсан тохиолдолд дараах байдлаар мэдээлэл өгнө үү.

### Алдаа гарсан үед бидэнд хэрхэн мэдээлэх вэ? [Anchor](https://docs.dayansoft.mn/support/d195\#%D0%B0%D0%BB%D0%B4%D0%B0%D0%B0-%D0%B3%D0%B0%D1%80%D1%81%D0%B0%D0%BD-%D2%AF%D0%B5%D0%B4-%D0%B1%D0%B8%D0%B4%D1%8D%D0%BD%D0%B4-%D1%85%D1%8D%D1%80%D1%85%D1%8D%D0%BD-%D0%BC%D1%8D%D0%B4%D1%8D%D1%8D%D0%BB%D1%8D%D1%85-%D0%B2%D1%8D)

1. **Яг ямар програмд** алдаа гарсныг тодорхойлно.
2. **Ямар цонх, ямар бүртгэл дээр** байсныг харуулна.
3. **Ямар үйлдэл хийж, ямар товч дарсны дараа** алдаа гарсныг тэмдэглэнэ.
4. Алдааны мессеж харагдаж байгаа хэсгийг **зураг эсвэл бичлэгээр** авч бидэн рүү чатаар илгээнэ.

Бид өгсөн мэдээлэлд үндэслэн алдааны шалтгааныг шалгаж, шаардлагатай тохиолдолд:

- алдааг засах;
- програмын үйл ажиллагааг сайжруулах;
- тухайн мессежийг хэрэглэгчид ойлгомжтой **монгол хэлээр** харуулах

хөгжүүлэлт, сайжруулалтыг хийнэ.

# Түгээмэл тохиолдож болох алдааны мессежүүд [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%82%D2%AF%D0%B3%D1%8D%D1%8D%D0%BC%D1%8D%D0%BB-%D1%82%D0%BE%D1%85%D0%B8%D0%BE%D0%BB%D0%B4%D0%BE%D0%B6-%D0%B1%D0%BE%D0%BB%D0%BE%D1%85-%D0%B0%D0%BB%D0%B4%D0%B0%D0%B0%D0%BD%D1%8B-%D0%BC%D0%B5%D1%81%D1%81%D0%B5%D0%B6%D2%AF%D2%AF%D0%B4)

## 1\. **The wait operation timed out** [Anchor](https://docs.dayansoft.mn/support/d195\#1-the-wait-operation-timed-out)

эсвэл

**The semaphore timeout period has expired**

### Шалтгаан [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%88%D0%B0%D0%BB%D1%82%D0%B3%D0%B0%D0%B0%D0%BD)

Тухайн үйлдлийг хийх үед програм серверээс мэдээлэл авах, мэдээлэл хадгалах зэрэг ажиллагаа удааширсан эсвэл сервертэй холболт тасарсан үед энэ мессеж гарч болно.

Жишээлбэл:

- мэдээлэл дуудах;
- мэдээлэл хадгалах;
- тайлан гаргах;
- бүртгэл нээх

үед интернетийн хурд удаан байх, холболт тасалдах зэрэг шалтгаанаар үүсч болно.

### Яах вэ? [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%8F%D0%B0%D1%85-%D0%B2%D1%8D)

1. Түр хүлээгээд үйлдлээ дахин хийнэ.
2. Интернет холболтоо шалгана.
3. Алдаа дахин гарвал **ямар цонх, ямар үйлдэл хийх үед** гарсныг зураг/бичлэгээр авч чатаар илгээнэ.

> **Анхаарах:** Танай мэдээллийн бааз онлайн серверт байрладаг учраас програм ашиглахад тогтвортой, өндөр хурдны интернет шаардлагатай.

## 2\. **A transport-level error has occurred when receiving result from the server. (provider: Session Provider, error: 19 - Physical connection is not usable)** [Anchor](https://docs.dayansoft.mn/support/d195\#2-a-transport-level-error-has-occurred-when-receiving-result-fro)

### Шалтгаан [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%88%D0%B0%D0%BB%D1%82%D0%B3%D0%B0%D0%B0%D0%BD-1)

Энэ алдаа нь програм серверээс мэдээлэл авах үед **сервертэй холбогдох сүлжээний холболт тасарсан** тохиолдолд үүсч болно.

Жишээлбэл:

- интернет түр тасарсан;
- Wi-Fi холболт тогтворгүй;
- байгууллагын дотоод сүлжээ тасарсан;
- сервер рүү чиглэсэн хандалт хаагдсан;
- интернет үйлчилгээ үзүүлэгчийн сүлжээнд асуудал гарсан

зэрэг шалтгаантай байж болно.

### Яах вэ? [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%8F%D0%B0%D1%85-%D0%B2%D1%8D-1)

1. Түр хүлээгээд үйлдлээ дахин хийнэ.
2. Интернет холболтоо шалгана.
3. Интернет хэвийн байгаа боловч алдаа үргэлжилбэл сүлжээний хандалтыг шалгуулна.

Хэрэв байгууллагын интернетээр Dayansoft-ийн онлайн серверт хандах боломжгүй байгаа бол **интернет үйлчилгээ үзүүлэгч байгууллагадаа** хандаж шалгуулна уу.

### Нэмэлтээр шалгах арга [Anchor](https://docs.dayansoft.mn/support/d195\#%D0%BD%D1%8D%D0%BC%D1%8D%D0%BB%D1%82%D1%8D%D1%8D%D1%80-%D1%88%D0%B0%D0%BB%D0%B3%D0%B0%D1%85-%D0%B0%D1%80%D0%B3%D0%B0)

Хэрэв компьютер Wi-Fi ашигладаг бол гар утасныхаа **Hotspot**-ыг асааж компьютерыг өөр интернетэд холбож үзэж болно.

- Hotspot ашиглахад програм хэвийн ажиллавал байгууллагын интернет, сүлжээний тохиргоотой холбоотой байх магадлалтай.
- Hotspot ашигласан ч алдаа хэвээр байвал алдааны зураг/бичлэгийг бидэнд илгээнэ үү.

## 3\. **Object reference not set to an instance of an object.** [Anchor](https://docs.dayansoft.mn/support/d195\#3-object-reference-not-set-to-an-instance-of-an-object)

### Шалтгаан [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%88%D0%B0%D0%BB%D1%82%D0%B3%D0%B0%D0%B0%D0%BD-2)

Энэ нь програмын дотоод ажиллагааны явцад үүссэн **техникийн шинжтэй алдаа** бөгөөд зөвхөн алдааны мессежийг хараад яг шалтгааныг тодорхойлох боломжгүй.

### Яах вэ? [Anchor](https://docs.dayansoft.mn/support/d195\#%D1%8F%D0%B0%D1%85-%D0%B2%D1%8D-2)

Алдаа гарсан үед:

1. Ямар програм ашиглаж байснаа;
2. Ямар цонхонд байснаа;
3. Ямар бүртгэл сонгосноо;
4. Ямар товч дарснаа;
5. Алдаа гарахаас өмнө ямар үйлдэл хийснээ

харуулсан **зураг эсвэл богино бичлэгийг** бидэнд чатаар илгээнэ үү.

Бид тухайн үйлдлийн дарааллыг шалгаж, алдааны шалтгааныг тодорхойлон засвар, сайжруулалт хийх боломжтой.
