# ⚙️ Үндсэн тохиргоо [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%E2%9A%99%EF%B8%8F-%D2%AF%D0%BD%D0%B4%D1%81%D1%8D%D0%BD-%D1%82%D0%BE%D1%85%D0%B8%D1%80%D0%B3%D0%BE%D0%BE)

Dayansoft ERP системд ажиллаж эхлэхээс өмнө **ямар төрлийн өгөгдөл бүртгэдэг, эдгээр өгөгдөл хоорондоо ямар хамааралтай** болохыг ойлгох нь чухал.

ERP системд өгөгдлийг ерөнхийд нь дараах 3 төрөлд авч үзэж болно.

- 🗂️ **Master data (Мастер дата)** – байгууллагын өдөр тутмын үйл ажиллагаанд байнга ашиглагддаг үндсэн объект, код, бүртгэл. Жишээ нь: ажилтан, харилцагч, бараа материал, хөрөнгө.
- 📚 **Reference data (Лавлах мэдээлэл)** – мастер дата болон гүйлгээнд сонголт болгон ашиглагддаг суурь тохиргоо, лавлах мэдээлэл. Жишээ нь: хэмжих нэгж, валют, төлбөрийн нөхцөл, байршил.
- 🔄 **Transaction data (Гүйлгээний мэдээлэл)** – байгууллагын өдөр тутмын үйл ажиллагааны явцад үүсдэг орлого, зарлага, худалдан авалт, борлуулалт, төлбөр, журнал зэрэг мэдээлэл.

Эдгээр нь хоорондоо уялдаатай ажилладаг. Тухайлбал, **бараа материалын мастер бүртгэл болон хэмжих нэгж зэрэг суурь мэдээллийг бүртгэсний дараа тухайн бараатай холбоотой худалдан авалт, борлуулалт, агуулахын хөдөлгөөн зэрэг гүйлгээг бүртгэнэ.**

Хэрэглэгчдийн түгээмэл гаргадаг алдаа нь суурь мэдээлэл, мастер датагаа зөв бүрдүүлэхээс өмнө шууд гүйлгээ бүртгэж эхлэхийг оролддог явдал юм. Тиймээс ERP системийг шинээр ашиглаж эхлэх үед **эхлээд суурь тохиргоо, лавлах мэдээлэл, мастер датагаа бүрдүүлж, дараа нь холбогдох гүйлгээг бүртгэх** зарчмыг баримтлахыг зөвлөж байна.

## 🎯 Үндсэн тохиргоо модулийн зорилго [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%8E%AF-%D2%AF%D0%BD%D0%B4%D1%81%D1%8D%D0%BD-%D1%82%D0%BE%D1%85%D0%B8%D1%80%D0%B3%D0%BE%D0%BE-%D0%BC%D0%BE%D0%B4%D1%83%D0%BB%D0%B8%D0%B9%D0%BD-%D0%B7%D0%BE%D1%80%D0%B8%D0%BB%D0%B3%D0%BE)

**Үндсэн тохиргоо** модуль нь Dayansoft ERP системийн суурь тохиргоо хийх, байгууллагын мастер дата болон лавлах мэдээллийг бүртгэх, системийн хэрэглэгч болон түүний эрхийг удирдах үндсэн модуль юм.

Энэ модулийн тохиргоо, бүртгэл нь **Санхүү, Худалдан авалт, Борлуулалт, Бараа материал, Хүний нөөц, Цалин, Үйлдвэрлэл** зэрэг бусад модулийн өдөр тутмын үйл ажиллагаанд ашиглагдана.

# 🧩 Функц, боломж [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%A7%A9-%D1%84%D1%83%D0%BD%D0%BA%D1%86-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6)

## 👤 1\. Систем хэрэглэгч [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%91%A4-1-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87)

Систем ашиглах ажилтан бүрт тусдаа хэрэглэгч үүсгэж, тухайн хэрэглэгчийн ажил үүрэгт тохирсон эрхийг тохируулна.

- ➕ Хэрэглэгч шинээр бүртгэх
- 🚫 Хэрэглэгчийг идэвхгүй болгох
- 🔒 Гүйлгээ хийх хугацааны хязгаар тохируулах
- 🛡️ Модуль, цонх тус бүрийн эрх тохируулах
- ✏️ **Нэмэх, харах, засах, устгах** үйлдлийн эрх тохируулах
- 📋 Эрхийн тохиргоог өөр хэрэглэгч рүү хуулах
- 📊 Тайлан харах эрх тохируулах
- 💳 Дансаар гүйлгээ хийх болон гүйлгээ харах эрх тохируулах

> 💡 **Зөвлөмж:** Нэг байгууллагад ажиллаж байгаа хүн бүрт тусдаа хэрэглэгч үүсгэх нь тухайн хэрэглэгчийн хийсэн бүртгэл, өөрчлөлтийг хянахад илүү тохиромжтой.

## 🏢 2\. Байгууллага [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%8F%A2-2-%D0%B1%D0%B0%D0%B9%D0%B3%D1%83%D1%83%D0%BB%D0%BB%D0%B0%D0%B3%D0%B0)

Байгууллагын үндсэн мэдээлэл болон системээс гарах баримт, тайланд ашиглагдах тохиргоог бүртгэнэ.

- 🏢 Байгууллагын үндсэн мэдээлэл тохируулах
- 🧾 Татварын холбогдох мэдээлэл тохируулах
- 📄 Байгууллагын баримтад ашиглах мэдээлэл тохируулах

## 🏬 3\. Салбар нэгж [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%8F%AC-3-%D1%81%D0%B0%D0%BB%D0%B1%D0%B0%D1%80-%D0%BD%D1%8D%D0%B3%D0%B6)

Байгууллагын салбар, нэгж болон өртгийн төвийг бүртгэж, тухайн салбартай холбоотой тохиргоог хийнэ.

- 🏬 Салбар нэгж үүсгэх
- 🎯 Өртгийн төв тохируулах
- 🧾 Салбар нэгжээр НӨАТ, НХАТ-ын данс тохируулах
- ⚙️ НХАТ-тай холбоотой тохиргоо хийх
- 💰 Бөөний борлуулалттай холбоотой НХАТ-ын тохиргоо хийх

## 👨‍💼 4\. Ажилтан, албан тушаал [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%91%A8%E2%80%8D%F0%9F%92%BC-4-%D0%B0%D0%B6%D0%B8%D0%BB%D1%82%D0%B0%D0%BD-%D0%B0%D0%BB%D0%B1%D0%B0%D0%BD-%D1%82%D1%83%D1%88%D0%B0%D0%B0%D0%BB)

Ажилтны мастер бүртгэлийг үүсгэж, ажилтантай холбоотой үндсэн мэдээлэл, гэрээ болон бусад тохиргоог хийнэ.

- 💼 Албан тушаал бүртгэх
- 👤 Ажилтны анкет бүртгэх
- 📝 Ажилтантай холбоотой гэрээ бүртгэх
- 📥 Ажилтны мэдээллийг Excel-ээр олноор импортлох
- 💳 Тооцооны данс тохируулах
- 💰 Үнийн жагсаалт тохируулах
- 🛒 Ажилтныг **Борлуулагч** болгон тохируулах

## 🤝 5\. Харилцагч [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%A4%9D-5-%D1%85%D0%B0%D1%80%D0%B8%D0%BB%D1%86%D0%B0%D0%B3%D1%87)

Харилцагчийн үндсэн мастер мэдээллийг бүртгэж, түүнтэй холбоотой борлуулалт, худалдан авалт, төлбөр болон бусад мэдээллийг нэг дороос хянах боломжтой.

- 👥 Харилцагчийн бүлэг үүсгэх
- 🧑‍💼 Харилцагчийн ерөнхий мэдээлэл бүртгэх
- 📞 Холбоо барих хүний мэдээлэл бүртгэх
- 🏦 Харилцах дансны мэдээлэл бүртгэх
- 📦 Худалдаж авах болон худалдах бараа, үйлчилгээний мэдээлэл тохируулах
- 💰 Үнийн мэдээлэл тохируулах
- 📝 Харилцагчтай холбоотой гэрээ бүртгэх
- 📎 Файл, нэмэлт мэдээлэл хадгалах
- 🏷️ Мета мэдээлэл тохируулах
- 🔗 Харилцагчтай холбоотой нэхэмжлэх, үнийн санал, төлбөрийн хуваарь, худалдан авалт, борлуулалт болон бусад бүртгэл рүү шилжих
- 🌐 Дотоод болон гадаад харилцагчийн тохиргоо хийх

## 📁 6\. Төсөл [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%93%81-6-%D1%82%D3%A9%D1%81%D3%A9%D0%BB)

Төсөлтэй холбоотой мэдээллийг бүртгэж, гүйлгээ болон тайланг төслөөр ангилан хянах боломжтой.

- ➕ Төсөл бүртгэх
- 🔗 Гүйлгээг төсөлтэй холбох
- 📊 Тайланг төслөөр шүүж харах

## 📑 7\. Гэрээ [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%93%91-7-%D0%B3%D1%8D%D1%80%D1%8D%D1%8D)

Байгууллагын гэрээний бүртгэл болон гэрээтэй холбоотой гүйлгээг хөтөлнө.

- 📝 Гэрээ бүртгэх
- 📒 Журнал бичилтэд гэрээ сонгох
- 🔗 Гүйлгээг гэрээтэй холбох
- 📊 Тайланг гэрээгээр шүүж харах

## 💬 8\. Харилцаа холбоо (CRM) [Anchor](https://docs.dayansoft.mn/erp/main/d019\#%F0%9F%92%AC-8-%D1%85%D0%B0%D1%80%D0%B8%D0%BB%D1%86%D0%B0%D0%B0-%D1%85%D0%BE%D0%BB%D0%B1%D0%BE%D0%BE-crm)

Харилцагч, ажилтан болон бусад холбоотой этгээдтэй хийсэн харилцаа, уулзалт, ажил үүргийг бүртгэх боломжтой.

- 🤝 Уулзалт, event бүртгэх
- 🎓 Сургалт бүртгэх
- 📞 Утасны харилцаа бүртгэх
- 📧 И-мэйл харилцаа бүртгэх
- ✅ Ажил үүрэг, task бүртгэх
- 📌 Даалгавар хуваарилах
- 📊 Даалгаврын биелэлтийг хянах
