## 📌 Журналын загвар гэж юу вэ? [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%93%8C-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B7%D0%B0%D0%B3%D0%B2%D0%B0%D1%80-%D0%B3%D1%8D%D0%B6-%D1%8E%D1%83-%D0%B2%D1%8D)

**Журналын загвар** нь байнга давтагддаг ажил гүйлгээний **дебет, кредит бичилтийг урьдчилан тохируулж**, баримт бүртгэх үед журналын бичилтийг автоматаар үүсгэх боломжийг олгоно.

Жишээлбэл:

- 💰 Цалингийн журнал
- 🏭 Дуусаагүй үйлдвэрлэлийн зардлын нэгтгэл
- 🏦 Харилцахын орлого, зарлага
- 🧾 НӨАТ хаалт
- 💼 ААНОАТ-ын зардал
- 💳 QPay орлого
- 🏦 Settlement орлого

Журналын загварыг **нэг удаа зөв тохируулснаар** дараагийн ажил гүйлгээнүүд дээр дахин дахин журналын данс сонгож оруулах шаардлагагүй болно.

> 💡 **Давуу тал:** Гар ажиллагааг багасгаж, ажилтны цагийг хэмнэхийн зэрэгцээ буруу дансанд журнал хийх болон бүртгэлийн алдааг багасгана.

# ➕ 1\. Журналын загвар үүсгэх [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%E2%9E%95-1-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B7%D0%B0%D0%B3%D0%B2%D0%B0%D1%80-%D2%AF%D2%AF%D1%81%D0%B3%D1%8D%D1%85)

**Санхүү бүртгэл → Журналын загвар** цонхонд орж **Шинэ (Ctrl+Insert)** товч дарна.

Дараах мэдээллийг оруулна:

| Талбар | Тайлбар |
| --- | --- |
| **Код** | Журналын загварын код. Дурын код өгөх боломжтой. 3 оронтой код ашиглахыг зөвлөж байна. |
| **Нэр** | Журналын загварын нэр. Ямар зориулалттай загвар болохыг ойлгомжтой нэрлэнэ. |

### 💡 Нэр өгөх жишээ [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%92%A1-%D0%BD%D1%8D%D1%80-%D3%A9%D0%B3%D3%A9%D1%85-%D0%B6%D0%B8%D1%88%D1%8D%D1%8D)

- `101` – Урьдчилгаа цалингийн журнал
- `102` – Сүүл цалингийн журнал
- `103` – Борлуулалт маркетингийн цалин
- `104` – QPay орлого
- `105` – Дуусаагүй үйлдвэрлэлийн нэгтгэл

# 🔄 2\. Журналын бичилт тохируулах [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%94%84-2-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B1%D0%B8%D1%87%D0%B8%D0%BB%D1%82-%D1%82%D0%BE%D1%85%D0%B8%D1%80%D1%83%D1%83%D0%BB%D0%B0%D1%85)

Журналын загварыг үүсгэсний дараа тухайн загвараар **ямар дебет, кредит бичилт хийхийг** тохируулна.

**Нэмэх (Ctrl+Insert)** товч дарж журналын мөр нэмнэ.

| Талбар | Тайлбар |
| --- | --- |
| **Багц** | Нэг журналын загварт хамаарах бичилтүүдийг багцлан дугаарлана. |
| **Дебет данс** | Дебетлэх дансыг сонгоно. |
| **Кредит данс** | Кредитлэх дансыг сонгоно. |
| **Мөнгөн гүйлгээ** | Тухайн бичилтэд хамаарах мөнгөн гүйлгээний үзүүлэлтийг сонгоно. |
| **Харилцагч** | Шаардлагатай тохиолдолд харилцагчийг сонгоно. |
| **Дараалал** | Журналын мөрүүдийн харагдах дарааллыг тохируулна. |
| **Дүн төрөл** | Тухайн мөрөнд ямар дүнгээр журнал үүсгэхийг сонгоно. |
| **Row** | Тухайн мөрийн дугаар. Томьёонд ашиглана. |
| **Томьёо** | Мөрүүдийн дүнг ашиглан тооцоолол хийх томьёо оруулна. |
| **Цалин үзүүлэлт** | Цалингийн журналын үед тухайн мөрөнд ашиглах цалингийн үзүүлэлтийг сонгоно. |

# 🧮 3\. Дүн төрөл [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%A7%AE-3-%D0%B4%D2%AF%D0%BD-%D1%82%D3%A9%D1%80%D3%A9%D0%BB)

**Дүнгийн төрөл** нь тухайн журналын мөрөнд **ямар эх үүсвэрийн дүнгээр бичилт хийхийг** тодорхойлно.

### 🔹 Үлдэгдэл [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%94%B9-%D2%AF%D0%BB%D0%B4%D1%8D%D0%B3%D0%B4%D1%8D%D0%BB)

Тухайн дансны **үлдэгдэл дүнгээр** журнал үүсгэнэ.

Жишээ:

> Дуусаагүй үйлдвэрлэлийн зардлын дансны үлдэгдлийг хаалтын бичилтээр нэгтгэх.

### 🔹 Салбар [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%94%B9-%D1%81%D0%B0%D0%BB%D0%B1%D0%B0%D1%80)

Нэг цалин бодолтоор байгууллагын бүх ажилтны цалинг бодож, цалингийн зардлыг **салбар бүрээр тусдаа дансанд** бүртгэх үед ашиглана.

Жишээ:

- Борлуулалтын салбар → Борлуулалтын цалингийн зардал
- Маркетингийн салбар → Маркетингийн цалингийн зардал
- Үйлдвэрлэл → Үйлдвэрлэлийн цалингийн зардал

> ⚠️ **Анхаарах:** Салбар тус бүрийн зардлын дансыг **Дансны төлөвлөгөө** хэсэгт урьдчилан үүсгэсэн байх шаардлагатай.

### 🔹 Салбар ажилтан [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%94%B9-%D1%81%D0%B0%D0%BB%D0%B1%D0%B0%D1%80-%D0%B0%D0%B6%D0%B8%D0%BB%D1%82%D0%B0%D0%BD)

Цалингийн зардлыг **ажилтан болон тухайн ажилтны харьяалагдах салбартай уялдуулан** журналд тусгах үед ашиглана.

> 💡 Энэ тохиргоог ашиглахын өмнө ажилтны салбарын мэдээлэл болон тухайн салбарын зардлын дансны тохиргоог шалгана.

# 📋 5\. Журналын загвар хувилах [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%93%8B-5-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B7%D0%B0%D0%B3%D0%B2%D0%B0%D1%80-%D1%85%D1%83%D0%B2%D0%B8%D0%BB%D0%B0%D1%85)

Ижил бүтэцтэй журналын загварыг шинээр гараар үүсгэхийн оронд өмнөх загвараа **хувилж** ашиглаж болно.

### Алхам [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC)

2. **Хувилах** товч дарна.
3. Шинэ загварын **Код, Нэр**-ийг өөрчилнө.
4. Шаардлагатай данс, тохиргоог өөрчилнө.
5. Хадгална.

> ⚡ **Зөвлөмж:** Ижил бүтэцтэй олон журнал ашигладаг бол хувилах аргыг ашигласнаар тохиргооны хугацааг хэмнэнэ.

### 📌 QPay журналын загвар үүсгэхийн өмнө [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%93%8C-qpay-%D0%B6%D1%83%D1%80%D0%BD%D0%B0%D0%BB%D1%8B%D0%BD-%D0%B7%D0%B0%D0%B3%D0%B2%D0%B0%D1%80-%D2%AF%D2%AF%D1%81%D0%B3%D1%8D%D1%85%D0%B8%D0%B9%D0%BD-%D3%A9%D0%BC%D0%BD%D3%A9)

QPay-ийн шимтгэл болон шимтгэлээс тооцох НӨАТ-ын хувь хэмжээ нь ашиглаж буй банк, төлбөрийн шийдлээс хамаарч болох тул:

1. Шимтгэлийн хувь хэмжээг тодорхойлох
2. НӨАТ тооцох эсэхийг тодорхойлох
3. Ямар дансанд бүртгэхээ шийдэх
4. Дараа нь журналын загвараа тохируулах

нь зөв.

# 🏭 9\. Дуусаагүй үйлдвэрлэлийн нэгтгэл [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%8F%AD-9-%D0%B4%D1%83%D1%83%D1%81%D0%B0%D0%B0%D0%B3%D2%AF%D0%B9-%D2%AF%D0%B9%D0%BB%D0%B4%D0%B2%D1%8D%D1%80%D0%BB%D1%8D%D0%BB%D0%B8%D0%B9%D0%BD-%D0%BD%D1%8D%D0%B3%D1%82%D0%B3%D1%8D%D0%BB)

Үйлдвэрлэлийн бүртгэл хөтөлдөг байгууллагад зардлын данснуудыг **Дуусаагүй үйлдвэрлэлийн нэгтгэл** дансанд тогтмол нэгтгэх шаардлагатай байдаг.

Ийм үед **Үлдэгдэл** дүнгийн төрлийг ашиглан журналын загвар үүсгэж болно.

### 🔄 Ашиглах дараалал [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%94%84-%D0%B0%D1%88%D0%B8%D0%B3%D0%BB%D0%B0%D1%85-%D0%B4%D0%B0%D1%80%D0%B0%D0%B0%D0%BB%D0%B0%D0%BB)

**Санхүү бүртгэл → Журнал бичилт**

1. Журналын загвараа сонгоно.
2. **Холбох** дарна.
3. Зардлын данснуудын үлдэгдлээр журнал автоматаар үүснэ.
4. **Нэмэх** дарна.
5. **Дуусаагүй үйлдвэрлэлийн нэгтгэл** дансыг сонгоно.
6. Хадгална.

Зардлын данснуудын тухайн үеийн үлдэгдлийг ашиглан **Дуусаагүй үйлдвэрлэлийн нэгтгэл** данс руу журналын бичилт үүснэ.

# 🧾 10\. Бусад хэрэглээ [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%F0%9F%A7%BE-10-%D0%B1%D1%83%D1%81%D0%B0%D0%B4-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D1%8D)

Журналын загварыг зөвхөн дээрх жишээнүүдээр хязгаарлахгүйгээр танай байгууллагад **давтамжтай хийгддэг ижил төрлийн журналын бичилтүүдэд** ашиглаж болно.

Жишээ нь:

| Журналын загвар | Ашиглах зориулалт |
| --- | --- |
| 💰 Цалингийн журнал | Цалингийн зардал, өглөгийн бичилт |
| 🧾 НӨАТ хаалт | НӨАТ авлага, өглөгийг хаах |
| 💼 ААНОАТ | ААНОАТ-ын зардал тооцох |
| 💳 QPay орлого | QPay шимтгэл, НӨАТ-ыг салгах |
| 🏦 Settlement орлого | Settlement-ийн орлогын бичилт |
| 🏭 Дуусаагүй үйлдвэрлэл | Үйлдвэрлэлийн зардлыг нэгтгэх |
| 🏦 Харилцах | Давтагддаг банкны гүйлгээний бичилт |

# ⚠️ Анхаарах зүйлс [Anchor](https://docs.dayansoft.mn/erp/finance/d050\#%E2%9A%A0%EF%B8%8F-%D0%B0%D0%BD%D1%85%D0%B0%D0%B0%D1%80%D0%B0%D1%85-%D0%B7%D2%AF%D0%B9%D0%BB%D1%81)

- Журналын загварын **дебет, кредит дансыг зөв тохируулна**.
- Томьёо ашиглаж байгаа бол **Row-ийн дугааруудыг зөв шалгана**.
- **Салбар** төрлийг ашиглах бол салбар бүрийн зардлын дансыг урьдчилан үүсгэнэ.
- QPay, Settlement зэрэг төлбөрийн шийдлийн шимтгэл, НӨАТ-ын **бодит нөхцөлийг урьдчилан тодорхойлно**.
- Журналын загварыг ашиглалтад оруулахаас өмнө **туршилтын гүйлгээгээр журналын бичилтийг шалгахыг зөвлөж байна**.
- Ижил бүтэцтэй загвар шинээр үүсгэхдээ **Хувилах** функцийг ашиглавал тохиргооны алдаа багасна.

> ✅ **Зөвлөмж:** Танай байгууллагад сар, долоо хоног бүр давтан хийгддэг журналын бичилтүүдийг жагсааж, тэдгээрийг журналын загвар болгон тохируулснаар санхүүгийн бүртгэлийн гар ажиллагааг мэдэгдэхүйц багасгах боломжтой.
