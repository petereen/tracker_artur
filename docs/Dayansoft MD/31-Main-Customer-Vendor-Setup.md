## Харилцаа холбоо гэж юу вэ? [Anchor](https://docs.dayansoft.mn/erp/main/d027\#%D1%85%D0%B0%D1%80%D0%B8%D0%BB%D1%86%D0%B0%D0%B0-%D1%85%D0%BE%D0%BB%D0%B1%D0%BE%D0%BE-%D0%B3%D1%8D%D0%B6-%D1%8E%D1%83-%D0%B2%D1%8D)

Аливаа бизнес, ажил хэрэг нь хүмүүсийн хоорондын харилцаа холбоонд үндэслэн хийгддэг. Харилцагч байгууллагатай үүссэн харилцаа, хэлэлцээр, уулзалт, тохиролцоо зэрэг мэдээллийг бүртгэхгүй орхисноор үл ойлголцол үүсэх, ажил хэрэг доголдох, бизнесийн эрсдэл болон алдагдал гарах зэрэг сөрөг үр дагавар гарч болно.

Зөвхөн харилцагч байгууллагатай төдийгүй **компанийн дотоод ажилтнуудтай хийх уулзалт, хэлэлцээр, ажил үүрэг, даалгавар** зэрэг харилцаа холбоог мөн бүртгэж болно.

Dayansoft ERP-ийн **Харилцаа холбоо** цонхонд эдгээр харилцаа, ажил үүрэг, даалгаврыг нэг дор бүртгэж, хянах боломжтой.

Жишээлбэл:

- Уулзалт
- Event
- Сургалт
- Утсаар ярьсан лог
- Мэйл
- Ажил үүрэг, даалгавар
- Task
- Байгууллагын үйл ажиллагааны онцлогоос хамаарах бусад төрлийн харилцаа холбоо

> **Яагаад бүртгэх хэрэгтэй вэ?**
> Харилцагч, ажилтан болон байгууллагын дотоодод үүссэн харилцаа холбоо, ажил үүргийг бүртгэснээр **хийгдсэн болон хийгдээгүй ажил, хоцорсон ажил, хариуцагч, биелэлтийг** эргэн хянах боломжтой. Ингэснээр хариуцлага тооцох, алдааг олж засах, ажлын процессыг сайжруулахад ашиглана.

# Харилцаа холбооны бүртгэл ашиглах жишээ [Anchor](https://docs.dayansoft.mn/erp/main/d027\#%D1%85%D0%B0%D1%80%D0%B8%D0%BB%D1%86%D0%B0%D0%B0-%D1%85%D0%BE%D0%BB%D0%B1%D0%BE%D0%BE%D0%BD%D1%8B-%D0%B1%D2%AF%D1%80%D1%82%D0%B3%D1%8D%D0%BB-%D0%B0%D1%88%D0%B8%D0%B3%D0%BB%D0%B0%D1%85-%D0%B6%D0%B8%D1%88%D1%8D%D1%8D)

Жишээлбэл, харилцагч байгууллагаас:

> “Ирэх долоо хоногт 100 ширхэг бараа авах боломжтой.”

гэсэн хүсэлт ирсэн гэж үзье.

Энэ тохиолдолд:

- **Харилцагч** → тухайн байгууллагыг сонгоно.
- **Хэн** → холбогдсон хүнийг сонгоно.
- **Огноо** → ярилцсан огноог оруулна.
- **Утга** → 100 ширхэг бараа авах хүсэлтийг тайлбарлана.
- **Төрөл** → Утсаар ярьсан / Борлуулалт гэх мэт төрлийг сонгоно.
- **Хариуцагч** → цаашид шийдвэрлэх ажилтныг сонгоно.
- **Биелэх хугацаа** → шийдвэрлэх эцсийн хугацааг оруулна.
- **Төлөв** → Шинэ / Хийгдэж байгаа гэх мэт төлөв сонгоно.
- Ажил дууссаны дараа **Биелүүлсэн**, **Тайлбар**, **Хаагдсан** мэдээллийг шинэчилнэ.

Ингэснээр тухайн харилцагчтай юу ярьсан, хэн хариуцаж байгаа, хэзээ дуусгах ёстой, ямар үр дүнд хүрсэн зэргийг дараа нь эргэн харах боломжтой болно.

# Жагсаалтаас хийх үйлдлүүд [Anchor](https://docs.dayansoft.mn/erp/main/d027\#%D0%B6%D0%B0%D0%B3%D1%81%D0%B0%D0%B0%D0%BB%D1%82%D0%B0%D0%B0%D1%81-%D1%85%D0%B8%D0%B9%D1%85-%D2%AF%D0%B9%D0%BB%D0%B4%D0%BB%D2%AF%D2%AF%D0%B4)

Харилцаа холбооны жагсаалтаас тухайн мөрөн дээр **хулганы баруун товч** дарж дараах үйлдлүүдийг хийнэ.

### Бүх харилцаа холбоог харах [Anchor](https://docs.dayansoft.mn/erp/main/d027\#%D0%B1%D2%AF%D1%85-%D1%85%D0%B0%D1%80%D0%B8%D0%BB%D1%86%D0%B0%D0%B0-%D1%85%D0%BE%D0%BB%D0%B1%D0%BE%D0%BE%D0%B3-%D1%85%D0%B0%D1%80%D0%B0%D1%85)

Тухайн харилцагчтай холбоотой **бүх харилцаа холбооны бүртгэлийг шүүж харуулна.**

### Харилцагч харах [Anchor](https://docs.dayansoft.mn/erp/main/d027\#%D1%85%D0%B0%D1%80%D0%B8%D0%BB%D1%86%D0%B0%D0%B3%D1%87-%D1%85%D0%B0%D1%80%D0%B0%D1%85)

Тухайн харилцаа холбоонд бүртгэгдсэн харилцагчийн **дэлгэрэнгүй бүртгэл рүү шууд шилжинэ.**

# Зөвлөмж [Anchor](https://docs.dayansoft.mn/erp/main/d027\#%D0%B7%D3%A9%D0%B2%D0%BB%D3%A9%D0%BC%D0%B6)

Харилцагч, ажилтан болон байгууллагын дотоодод үүссэн ажил, уулзалт, тохиролцоо, даалгаврыг зөвхөн тухайн ажилтны санах ойд үлдээхгүй, **Dayansoft ERP-д бүртгэж хэвших** нь зүйтэй.

- Хэзээ дуусгах ёстой?
- Хэд хоногоор хоцорсон?
- Ямар үр дүнд хүрсэн?
