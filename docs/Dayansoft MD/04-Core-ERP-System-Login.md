# Системд нэвтрэх [Anchor](https://docs.dayansoft.mn/erp/d016\#%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B4-%D0%BD%D1%8D%D0%B2%D1%82%D1%80%D1%8D%D1%85)

Dayansoft ERP системийг ашиглаж эхлэхийн өмнө өөрийн **систем хэрэглэгч, нууц үг, мэдээллийн бааз болон лицензийн тохиргоо** зөв эсэхийг шалгана.

## 1\. Dayansoft ERP системд нэвтрэх [Anchor](https://docs.dayansoft.mn/erp/d016\#1-dayansoft-erp-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B4-%D0%BD%D1%8D%D0%B2%D1%82%D1%80%D1%8D%D1%85)

1. Компьютерын Desktop дээр байрлах **Dayansoft ERP** програмын icon дээр 2 удаа дарна.
2. Нэвтрэх цонх нээгдэнэ.
3. Өөрийн **Хэрэглэгч** болон **Нууц үг**-ээ оруулна.
4. **Нэвтрэх** товч дарна.

![ERPLoginWindow](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/06.d016/ERPLoginWindow.png)

> **Анх удаа нэвтэрч байгаа бол:**
> Танай байгууллагын **Admin** хэрэглэгчээр нэвтэрч, бусад ажилтнуудад зориулсан систем хэрэглэгч үүсгэж, эрх тохируулна.
> Олон ажилтан ашигладаг байгууллага бүр ажилтан тус бүрд тусдаа хэрэглэгч үүсгэхийг зөвлөж байна. Ингэснээр хэн ямар бүртгэл, өөрчлөлт хийснийг хянах боломжтой.

### Нэвтрэх цонхны талбарууд [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BD%D1%8D%D0%B2%D1%82%D1%80%D1%8D%D1%85-%D1%86%D0%BE%D0%BD%D1%85%D0%BD%D1%8B-%D1%82%D0%B0%D0%BB%D0%B1%D0%B0%D1%80%D1%83%D1%83%D0%B4)

**Бааз**
Олон мэдээллийн бааз ашигладаг байгууллага тухайн үед хандах баазаа сонгоно.

> Нэг компьютероос Dayansoft ERP програмыг хэд хэдэн удаа нээж, өөр өөр мэдээллийн баазад зэрэг хандаж болно.

**Хэрэглэгч**
Танд олгосон систем хэрэглэгчийн нэр эсвэл мэйл хаягийг оруулна.

**Нууц үг**
Тухайн хэрэглэгчийн нууц үгийг оруулна.

**Нэвтрэх** товч дарж системд нэвтэрнэ.

### Анхдагч Admin хэрэглэгч [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%B0%D0%BD%D1%85%D0%B4%D0%B0%D0%B3%D1%87-admin-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87)

Програмыг шинээр суулгасан үед системийн **Admin** хэрэглэгч анхдагч нууц үгтэй байдаг. Анхны нэвтрэлтийн дараа Admin нууц үгийг **заавал солихыг** зөвлөж байна.

> ⚠️ **Аюулгүй байдлын зөвлөмж**
> Анхдагч нууц үгийг хэвээр ашиглахгүй байх. Admin хэрэглэгч нь бүх системийн тохиргоо болон хэрэглэгчийн эрхэд хандах боломжтой тул хүчтэй, бусдад мэдэгдэхгүй нууц үг ашиглана уу.

* * *

# Програмын icon харагдахгүй бол [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D1%8B%D0%BD-icon-%D1%85%D0%B0%D1%80%D0%B0%D0%B3%D0%B4%D0%B0%D1%85%D0%B3%D2%AF%D0%B9-%D0%B1%D0%BE%D0%BB)

Хэрэв Desktop дээр **Dayansoft ERP** icon байхгүй болсон бол програмын суулгасан хавтас дотроос `Dayan.exe` файлыг олоод Desktop дээр shortcut үүсгэнэ.

Ихэнх тохиолдолд програм:

`D:\Dayansoft ERP\Dayan.exe`

замд байрласан байж болох боловч компьютер бүрийн суулгалтын зам өөр байж болно.

### Shortcut үүсгэх [Anchor](https://docs.dayansoft.mn/erp/d016\#shortcut-%D2%AF%D2%AF%D1%81%D0%B3%D1%8D%D1%85)

1. **Dayansoft ERP** програмын хавтсыг нээнэ.
2. `Dayan.exe` файлыг олно.
3. Файл дээр хулганы баруун товч дарна.
4. **Send to → Desktop (create shortcut)** сонгоно.
5. Desktop дээр үүссэн shortcut-аар програмыг ажиллуулна.

![CreateERPShortcut](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/06.d016/CreateERPShortcut.png)

Хэрэв програмын файл огт байхгүй бол **[Dayansoft ERP суулгах заавар](https://docs.dayansoft.mn/erp/d014)**-ын дагуу дахин суулгана уу.

# Нууц үг солих [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3-%D1%81%D0%BE%D0%BB%D0%B8%D1%85)

Системд нэвтэрсний дараа өөрийн нууц үгийг солих боломжтой.

1. Цонхны дээд хэсэгт харагдах **нэвтэрсэн хэрэглэгчийн нэр** дээр дарна.
2. **Нууц үг солих / Change password** сонгоно.

![ChangePassword0](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/06.d016/ChangePassword0.png)

Дараах мэдээллийг оруулна.

- **Хуучин нууц үг** — одоо ашиглаж байгаа нууц үг
- **Шинэ нууц үг** — ашиглах шинэ нууц үг
- **Шинэ нууц үг** — шинэ нууц үгээ давтан оруулна

![ChangePassword](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/06.d016/ChangePassword.png)

### Нууц үг сонгох зөвлөмж [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3-%D1%81%D0%BE%D0%BD%D0%B3%D0%BE%D1%85-%D0%B7%D3%A9%D0%B2%D0%BB%D3%A9%D0%BC%D0%B6)

Нууц үгэнд:

- нэр;
- төрсөн он, сар, өдөр;
- утасны дугаар;
- байгууллагын нэр;
- бусад хүн амархан таах мэдээлэл

ашиглахаас зайлсхийж, бусад системд ашигладаг нууц үгээ давхар ашиглахгүй байхыг зөвлөж байна.

# Нууц үгээ мартсан бол [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3%D1%8D%D1%8D-%D0%BC%D0%B0%D1%80%D1%82%D1%81%D0%B0%D0%BD-%D0%B1%D0%BE%D0%BB)

### Энгийн хэрэглэгч [Anchor](https://docs.dayansoft.mn/erp/d016\#%D1%8D%D0%BD%D0%B3%D0%B8%D0%B9%D0%BD-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87)

Хэрэв системийн хэрэглэгчийн нууц үгээ мартсан бол байгууллагынхаа **Admin хэрэглэгчид** хандана.

Admin хэрэглэгч:

**Үндсэн тохиргоо → Систем хэрэглэгч**

цонхноос тухайн хэрэглэгчийн нууц үгийг шинэчилж өгнө.

### Admin хэрэглэгч нууц үгээ мартсан бол [Anchor](https://docs.dayansoft.mn/erp/d016\#admin-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87-%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3%D1%8D%D1%8D-%D0%BC%D0%B0%D1%80%D1%82%D1%81%D0%B0%D0%BD-%D0%B1%D0%BE%D0%BB)

Admin хэрэглэгчийн нууц үгийг мартсан, нэвтэрч чадахгүй тохиолдолд **[Admin нууц үг reset хийх хүсэлт](https://dayansoft.bitrix24.site/ERPResetAdminPassword/) илгээнэ.**

# Компьютераас түр холдох бол [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BA%D0%BE%D0%BC%D0%BF%D1%8C%D1%8E%D1%82%D0%B5%D1%80%D0%B0%D0%B0%D1%81-%D1%82%D2%AF%D1%80-%D1%85%D0%BE%D0%BB%D0%B4%D0%BE%D1%85-%D0%B1%D0%BE%D0%BB)

Компьютераа түр орхих үед бусад хүн таны хэрэглэгчээр систем ашиглахаас сэргийлж **Logout** хийнэ.

1. Цонхны дээд хэсэгт байрлах нэвтэрсэн хэрэглэгчийн нэр дээр дарна.
2. **Logout** сонгоно.

> **Зөвлөмж:** Хэрэглэгч бүр өөрийн нэрээр нэвтэрч ашиглах нь системийн бүртгэл, хяналт болон аюулгүй байдалд чухал.

# Нэвтэрч чадахгүй байна уу? [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BD%D1%8D%D0%B2%D1%82%D1%8D%D1%80%D1%87-%D1%87%D0%B0%D0%B4%D0%B0%D1%85%D0%B3%D2%AF%D0%B9-%D0%B1%D0%B0%D0%B9%D0%BD%D0%B0-%D1%83%D1%83)

**Нэвтрэх** товч дарсны дараа алдааны мессэж гарвал эхлээд мессэжийг анхааралтай уншина уу.

Доорх хүснэгтээс өөрийн харж буй алдаатай тохирох шалтгааныг олоод шийдлийг дагана.

| № | Асуудал | Юу хийх вэ? |
| --- | --- | --- |
| 1 | Хэрэглэгчийн нэр/нууц үг буруу | Хэрэглэгч, нууц үг, хэлний тохиргоо, Caps Lock шалгах |
| 2 | Лиценз аваагүй | Admin хэрэглэгч лиценз олгох |
| 3 | Лицензийн хугацаа дууссан | Лицензийн төлбөр/сунгалтаа шалгах |
| 4 | Үйлчилгээний гэрээ баталгаажаагүй | Гэрээг баталгаажуулж илгээх |
| 5 | Windows update / Restart шаардлагатай | Windows update хийж Restart хийх |
| 6 | Updating дээр гацсан | Интернет шалгаад дахин нэвтрэх |
| 7 | Сервер/баазтай холбогдохгүй | Интернет эсвэл байгууллагын серверийн холболт шалгах |
| 8 | Antivirus шинэчлэл блоклосон | Dayansoft-ийг зөвшөөрөгдсөн жагсаалтад нэмэх |
| 9 | Shortcut устсан | `Dayan.exe`-ээс шинэ shortcut үүсгэх |
| 10 | Shortcut-ийн зам буруу / exe устсан | Програмыг дахин суулгах |

# 1\. “Хэрэглэгчийн нэр эсвэл нууц үг буруу байна!” [Anchor](https://docs.dayansoft.mn/erp/d016\#1-%E2%80%9C%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87%D0%B8%D0%B9%D0%BD-%D0%BD%D1%8D%D1%80-%D1%8D%D1%81%D0%B2%D1%8D%D0%BB-%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3-%D0%B1%D1%83%D1%80%D1%83%D1%83-%D0%B1%D0%B0%D0%B9%D0%BD%D0%B0-%E2%80%9D)

Дараах төрлийн мессэж гарч болно.

> **“... хэрэглэгчийн нэр эсвэл нууц үг буруу байна!”**

Эхлээд дараах зүйлсийг шалгана.

### Шалгах зүйлс [Anchor](https://docs.dayansoft.mn/erp/d016\#%D1%88%D0%B0%D0%BB%D0%B3%D0%B0%D1%85-%D0%B7%D2%AF%D0%B9%D0%BB%D1%81)

- Хэрэглэгчийн нэрээ зөв оруулсан эсэх
- Нууц үгээ зөв оруулсан эсэх
- **Caps Lock** асаалттай эсэх
- Гарны хэл **MN / EN** зөв эсэх
- **Хэрэглэгч** хэсэгт нууц үгээ андуурч оруулаагүй эсэх
- Зөв **Бааз** сонгосон эсэх

Хэрэв хэрэглэгчийн нэрээ мэдэхгүй бол байгууллагынхаа **Admin хэрэглэгчээс** лавлана.

Admin хэрэглэгч:

**Үндсэн тохиргоо → Систем хэрэглэгч**

цонхноос хэрэглэгчийн бүртгэлийг шалгаж, шаардлагатай бол нууц үгийг шинэчилнэ.

### Admin бус хэрэглэгчийн нууц үг мартсан бол [Anchor](https://docs.dayansoft.mn/erp/d016\#admin-%D0%B1%D1%83%D1%81-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87%D0%B8%D0%B9%D0%BD-%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3-%D0%BC%D0%B0%D1%80%D1%82%D1%81%D0%B0%D0%BD-%D0%B1%D0%BE%D0%BB)

Admin хэрэглэгч нууц үгийг шинэчилж өгнө.

### Admin хэрэглэгчийн нууц үг мартсан бол [Anchor](https://docs.dayansoft.mn/erp/d016\#admin-%D1%85%D1%8D%D1%80%D1%8D%D0%B3%D0%BB%D1%8D%D0%B3%D1%87%D0%B8%D0%B9%D0%BD-%D0%BD%D1%83%D1%83%D1%86-%D2%AF%D0%B3-%D0%BC%D0%B0%D1%80%D1%82%D1%81%D0%B0%D0%BD-%D0%B1%D0%BE%D0%BB)

Даянсофт ХХК-ийн тусламжийн сувгаар хүсэлт илгээнэ.

> ⚠️ **Анхаарах:** Нууц үгээ бусдад илгээхгүй. Тусламж авахдаа шаардлагатай мэдээллээ өгч, нууц үгээ ил задгай дамжуулахгүй байхыг зөвлөж байна.

# 2\. “Нэвтрэх лиценз аваагүй байна!” [Anchor](https://docs.dayansoft.mn/erp/d016\#2-%E2%80%9C%D0%BD%D1%8D%D0%B2%D1%82%D1%80%D1%8D%D1%85-%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7-%D0%B0%D0%B2%D0%B0%D0%B0%D0%B3%D2%AF%D0%B9-%D0%B1%D0%B0%D0%B9%D0%BD%D0%B0-%E2%80%9D)

![InstallERP11](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/06.d016/InstallERP11.png)

Энэ мессэж гарвал тухайн компьютерт Dayansoft ERP ашиглах лиценз олгогдоогүй эсвэл өмнө нь олгосон лиценз тухайн компьютерт тохирохоо больсон байна.

### Яах вэ? [Anchor](https://docs.dayansoft.mn/erp/d016\#%D1%8F%D0%B0%D1%85-%D0%B2%D1%8D)

Эхлээд байгууллагынхаа **Admin хэрэглэгчид** хандана.

**Үндсэн тохиргоо → Систем хэрэглэгч → Компьютер лиценз**

хэсгээс тухайн компьютерт лиценз олгоно.

Хэрэв Admin хэрэглэгч лиценз олгох боломжгүй бол **Лиценз хүсэлт** илгээнэ.

### Лиценз дахин авах шаардлагатай түгээмэл тохиолдол [Anchor](https://docs.dayansoft.mn/erp/d016\#%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7-%D0%B4%D0%B0%D1%85%D0%B8%D0%BD-%D0%B0%D0%B2%D0%B0%D1%85-%D1%88%D0%B0%D0%B0%D1%80%D0%B4%D0%BB%D0%B0%D0%B3%D0%B0%D1%82%D0%B0%D0%B9-%D1%82%D2%AF%D0%B3%D1%8D%D1%8D%D0%BC%D1%8D%D0%BB-%D1%82%D0%BE%D1%85%D0%B8%D0%BE%D0%BB%D0%B4%D0%BE%D0%BB)

- Шинэ компьютерт програм суулгасан
- Програмыг өөр компьютерт шилжүүлсэн
- Windows-ийн томоохон шинэчлэлтийн дараа Hardware ID өөрчлөгдсөн
- Hard disk сольсон
- Mainboard зэрэг төхөөрөмж сольсон
- Компьютерийн төхөөрөмжийн өөрчлөлтөөс Hardware ID өөрчлөгдсөн

# 3\. Лицензийн хугацаа дууссан [Anchor](https://docs.dayansoft.mn/erp/d016\#3-%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D0%B8%D0%B9%D0%BD-%D1%85%D1%83%D0%B3%D0%B0%D1%86%D0%B0%D0%B0-%D0%B4%D1%83%D1%83%D1%81%D1%81%D0%B0%D0%BD)

Лицензийн хугацаа дууссан үед системд лицензийн хугацаа дууссан тухай мессэж харуулна.

Лиценз дуусахаас өмнө систем сануулга харуулах бөгөөд лицензийн төлбөр, сунгалтын асуудлаа шалгана уу.

Зарим тохиолдолд систем өмнөх хугацааны мэдээллийг **харах, засварлах хязгаарлагдмал горимоор** нэвтрэх боломж олгодог.

> Энэ үед шинэ хугацааны ажил гүйлгээг хэвийн бүртгэх боломжгүй байж болно.

# 8\. Antivirus шинэчлэлтийг блоклосон [Anchor](https://docs.dayansoft.mn/erp/d016\#8-antivirus-%D1%88%D0%B8%D0%BD%D1%8D%D1%87%D0%BB%D1%8D%D0%BB%D1%82%D0%B8%D0%B9%D0%B3-%D0%B1%D0%BB%D0%BE%D0%BA%D0%BB%D0%BE%D1%81%D0%BE%D0%BD)

> ⚠️ **Анхаарах:** Antivirus-ийг бүрэн унтраах нь компьютерийн хамгаалалтыг сулруулдаг. Зөвхөн түр хугацаанд хамгаалалтыг унтраах шаардлагатай гэж үзвэл байгууллагын IT ажилтан эсвэл системийн администратортой зөвлөлдөнө.

Энэ тохиолдолд дараах зааварчилгааны дагуу програмын шинэчлэлээ авна уу:

1. Компьютерын баруун доод буланд байрлах програмуудын жагсаалт руу нэвтэрч антивирусны програмаа олно.
![02](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/06.d016/02.png)   2. Антивирусны програм дээр хулганы баруун товчийг дарна.
2. Антивирусны програмын төрлөөс хамаарсч өөр өөр цэс, сонголтууд байгаа. Түгээмэл жишээг дор дурдая. Ер нь бол логик дараалал, ажиллагаа нь ижил төстэй.
a. Avast програмтай бол Avast shield control -> Disable for 10 minutes сонгоно.
b. Kaspersky програмтай бол Pause protection -> Pause minute сонгоно.
3. Ok дарна.
4. Dayansoft програмд Нэвтрэх товч дарж, шинэчлэх цонхноос Install товч дарж шинэчилнэ.
5. 10 минутын дараа антивирусны програм автоматаар идэвхижнэ.
