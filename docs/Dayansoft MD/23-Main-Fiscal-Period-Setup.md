# НӨАТ суутган төлөгч болох [Anchor](https://docs.dayansoft.mn/erp/main/d022\#%D0%BD%D3%A9%D0%B0%D1%82-%D1%81%D1%83%D1%83%D1%82%D0%B3%D0%B0%D0%BD-%D1%82%D3%A9%D0%BB%D3%A9%D0%B3%D1%87-%D0%B1%D0%BE%D0%BB%D0%BE%D1%85)

Dayansoft ERP системийг анх ашиглаж эхлэх үед **НӨАТ суутган төлөгч биш** байсан байгууллага үйл ажиллагааны явцад НӨАТ суутган төлөгч болох тохиолдол түгээмэл байдаг.

НӨАТ суутган төлөгч болох өдрийг хуульд заасан эрх бүхий байгууллагаас танай байгууллагад мэдэгдэж, эхлээд **татварын системд НӨАТ суутган төлөгчийн бүртгэл** хийгдэнэ.

Татварын системд бүртгэл хийгдсэний дараа Dayansoft ERP болон Dayansoft POS системд НӨАТ суутган төлөгчийн тохиргоог шинэчилнэ.

> 💡 **Товчхондоо**
>
> **Татварын системд бүртгэгдэнэ → Dayansoft ERP/POS тохиргоо шинэчлэгдэнэ → НӨАТ тооцож баримт хэвлэнэ**

# 4\. Dayansoft POS дээр баримт хэвлэх боломжгүй болсон бол [Anchor](https://docs.dayansoft.mn/erp/main/d022\#4-dayansoft-pos-%D0%B4%D1%8D%D1%8D%D1%80-%D0%B1%D0%B0%D1%80%D0%B8%D0%BC%D1%82-%D1%85%D1%8D%D0%B2%D0%BB%D1%8D%D1%85-%D0%B1%D0%BE%D0%BB%D0%BE%D0%BC%D0%B6%D0%B3%D2%AF%D0%B9-%D0%B1%D0%BE%D0%BB%D1%81%D0%BE%D0%BD-%D0%B1%D0%BE%D0%BB)

Энэ үед баримт хэвлэхэд:

> **“ebarimt (ERROR) ... татвар төлөгч нь НӨАТ суутган төлөгч мөн тул ... баримтанд НӨАТ-г тооцоолох ёстой!”**

# 7\. НӨАТ суутган төлөгч болох үед барааны үнэ автоматаар өөрчлөгдөхгүй [Anchor](https://docs.dayansoft.mn/erp/main/d022\#7-%D0%BD%D3%A9%D0%B0%D1%82-%D1%81%D1%83%D1%83%D1%82%D0%B3%D0%B0%D0%BD-%D1%82%D3%A9%D0%BB%D3%A9%D0%B3%D1%87-%D0%B1%D0%BE%D0%BB%D0%BE%D1%85-%D2%AF%D0%B5%D0%B4-%D0%B1%D0%B0%D1%80%D0%B0%D0%B0%D0%BD%D1%8B-%D2%AF%D0%BD%D1%8D-%D0%B0%D0%B2%D1%82%D0%BE%D0%BC%D0%B0%D1%82%D0%B0%D0%B0%D1%80-%D3%A9%D3%A9%D1%80%D1%87%D0%BB%D3%A9%D0%B3%D0%B4%D3%A9)

НӨАТ суутган төлөгч болсон үед танай байгууллагын **бараа, үйлчилгээний үнэ автоматаар өөрчлөгдөхгүй.**

Зөвхөн НӨАТ суутган төлөгчийн төлөв өөрчлөгдөж, тухайн үнээс НӨАТ-ыг тооцож салгана.

### Жишээ [Anchor](https://docs.dayansoft.mn/erp/main/d022\#%D0%B6%D0%B8%D1%88%D1%8D%D1%8D)

НӨАТ суутган төлөгч болохоос өмнө:

**Ундаа → 1,100₮**

гэж системд тохируулсан гэж үзье.

НӨАТ суутган төлөгч болсны дараа систем үнийг автоматаар:

- НӨАТ-гүй үнэ: **1,000₮**
- НӨАТ: **100₮**
- Нийт: **1,100₮**

гэж салгаж тооцно.

> ⚠️ **Анхаар**
>
> НӨАТ суутган төлөгч болсон үед **борлуулалтын үнэ автоматаар өсөхгүй, буурахгүй.**
>
> Зөвхөн одоо байгаа үнийг НӨАТ-тай/НӨАТ-гүй дүнгээр ялган тооцно.

# 8\. НӨАТ суутган төлөгч болох үед үнээ өөрчлөх [Anchor](https://docs.dayansoft.mn/erp/main/d022\#8-%D0%BD%D3%A9%D0%B0%D1%82-%D1%81%D1%83%D1%83%D1%82%D0%B3%D0%B0%D0%BD-%D1%82%D3%A9%D0%BB%D3%A9%D0%B3%D1%87-%D0%B1%D0%BE%D0%BB%D0%BE%D1%85-%D2%AF%D0%B5%D0%B4-%D2%AF%D0%BD%D1%8D%D1%8D-%D3%A9%D3%A9%D1%80%D1%87%D0%BB%D3%A9%D1%85)

Хэрэв НӨАТ суутган төлөгч болохдоо бараа, үйлчилгээний **борлуулах үнийг өөрчлөх** шаардлагатай бол:

**Борлуулалт → Үнийн тохиргоо**
