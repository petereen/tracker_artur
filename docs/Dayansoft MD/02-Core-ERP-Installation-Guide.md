### Алхам 1\. Програм суулгах [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-1-%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC-%D1%81%D1%83%D1%83%D0%BB%D0%B3%D0%B0%D1%85)

Шинэ компьютерт Dayansoft ERP програмыг дээрх **програм суулгах зааврын дагуу** татаж суулгана.

Өмнө нь програм суулгасан бол энэ алхмыг алгасаж болно.

### Алхам 2\. Hardware ID авах [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-2-hardware-id-%D0%B0%D0%B2%D0%B0%D1%85)

Нэвтрэх цонхны зүүн доод хэсэгт харагдах **Hardware ID** буюу 20 оронтой сериал дугаарыг хуулж **Admin хэрэглэгчдээ** илгээнэ.

![LicenseERP1](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/04.d014/LicenseERP1.png)

> ⚠️ **Чухал:**
> Hardware ID-г **гараар бичихгүй**, шууд **Copy → Paste** хийж илгээхийг зөвлөж байна. Гараар бичвэл цифр, үсэг алдах эрсдэлтэй.

### Алхам 3\. Admin лиценз олгох [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-3-admin-%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7-%D0%BE%D0%BB%D0%B3%D0%BE%D1%85)

Admin хэрэглэгч дараах цэс рүү орно:

**Үндсэн тохиргоо → Систем хэрэглэгч → Компьютер лиценз**

Тохирох мөрийн **Hardware ID** баганад шинэ компьютероос авсан Hardware ID-г оруулна.

**Хэрэглэгч тайлбар** хэсэгт тухайн хэрэглэгчийн **албан тушаал, нэрийг** бичээд **Хадгалах** товч дарна.

![LicenseERP2](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/04.d014/LicenseERP2.png)

### 🔄 Өмнөх лицензийг өөр компьютерт шилжүүлэх [Anchor](https://docs.dayansoft.mn/erp/d014\#%F0%9F%94%84-%D3%A9%D0%BC%D0%BD%D3%A9%D1%85-%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D0%B8%D0%B9%D0%B3-%D3%A9%D3%A9%D1%80-%D0%BA%D0%BE%D0%BC%D0%BF%D1%8C%D1%8E%D1%82%D0%B5%D1%80%D1%82-%D1%88%D0%B8%D0%BB%D0%B6%D2%AF%D2%AF%D0%BB%D1%8D%D1%85)

Өмнө олгосон лицензийг шилжүүлэх бол тухайн мөрийн **Hardware ID**-г шинэ компьютерын Hardware ID-гаар солино.

**Хадгалах** товч дарсны дараа лиценз шинэ компьютерт шилжинэ.

> 💡 **Жишээ:**
> Ажилтан шинэ компьютертэй болсон бол шинэ компьютерын Hardware ID-г авч, өмнөх лицензийн мөрөнд шинэ Hardware ID-г оруулж хадгална.

### Алхам 4\. Лиценз шинэчлэх [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-4-%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7-%D1%88%D0%B8%D0%BD%D1%8D%D1%87%D0%BB%D1%8D%D1%85)

Admin лиценз олгосны дараа шинэ компьютероос нэвтрэх цонхны зүүн доод буланд байрлах **Лиценз шинэчлэх** товчийг дарна.

![LicenseERP1](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/04.d014/LicenseERP1.png)

### Алхам 5\. Системд нэвтрэх [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-5-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC%D0%B4-%D0%BD%D1%8D%D0%B2%D1%82%D1%80%D1%8D%D1%85)

# 🏢 Лицензтэй компьютероос өөр байгууллагын бааз руу хандах [Anchor](https://docs.dayansoft.mn/erp/d014\#%F0%9F%8F%A2-%D0%BB%D0%B8%D1%86%D0%B5%D0%BD%D0%B7%D1%82%D1%8D%D0%B9-%D0%BA%D0%BE%D0%BC%D0%BF%D1%8C%D1%8E%D1%82%D0%B5%D1%80%D0%BE%D0%BE%D1%81-%D3%A9%D3%A9%D1%80-%D0%B1%D0%B0%D0%B9%D0%B3%D1%83%D1%83%D0%BB%D0%BB%D0%B0%D0%B3%D1%8B%D0%BD-%D0%B1%D0%B0%D0%B0%D0%B7-%D1%80%D1%83%D1%83-%D1%85%D0%B0%D0%BD%D0%B4%D0%B0%D1%85)

Өмнө нь Dayansoft ERP суулгасан компьютероос **өөр компанийн мэдээллийн бааз** руу хандах шаардлагатай бол тухайн мэдээллийн баазын **Admin хэрэглэгч** лиценз олгоно.

Хэрэв шинээр хандах гэж буй компанийн **Admin хэрэглэгч нь та өөрөө** бол [лиценз хүсэлтийн форм](https://dayansoft.bitrix24.site/erp2/) бөглөж хүсэлт илгээнэ.

Даянсофт ХХК-аас хүсэлтийг шалгаж, Admin хэрэглэгчийн лиценз олгосны дараа бүртгэлтэй мэйл хаягаар хариу өгнө.

### ♻️ Програм дахин суулгах [Anchor](https://docs.dayansoft.mn/erp/d014\#%E2%99%BB%EF%B8%8F-%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC-%D0%B4%D0%B0%D1%85%D0%B8%D0%BD-%D1%81%D1%83%D1%83%D0%BB%D0%B3%D0%B0%D1%85)

Өмнө нь тухайн компьютерт лиценз олгогдсон бөгөөд програмыг устгаад дахин суулгасан, эсвэл компьютерыг форматлаад дахин суулгасан бол **лицензийг дахин шинээр олгох шаардлагагүй** тохиолдолд шууд нэвтэрч болно.

### 🆔 Hardware ID [Anchor](https://docs.dayansoft.mn/erp/d014\#%F0%9F%86%94-hardware-id)

Hardware ID нь тухайн компьютерт лиценз олгоход ашиглагддаг дахин давтагдашгүй дугаар юм.

> ⚠️ **Hardware ID өөрчлөгдөх боломжтой нөхцөлүүд:**
>
> - Hard disk солих
> - Main board солих
> - Зарим Windows update-ийн дараа
>
> Hardware ID өөрчлөгдвөл Admin хэрэглэгч лицензийг шинэ Hardware ID руу **шилжүүлэх** шаардлагатай.

### 🪟 Үйлдлийн систем [Anchor](https://docs.dayansoft.mn/erp/d014\#%F0%9F%AA%9F-%D2%AF%D0%B9%D0%BB%D0%B4%D0%BB%D0%B8%D0%B9%D0%BD-%D1%81%D0%B8%D1%81%D1%82%D0%B5%D0%BC)

Dayansoft програм нь **Windows 10/11 OS** үйлдлийн системтэй компьютерт суулгана.

MacOS болон тоног төхөөрөмжийн шаардлагын талаар [дэлгэрэнгүй мэдээлэл](https://docs.dayansoft.mn/faq/d011) харна уу.

> ⚠️ **Шаардлага хангахгүй компьютер дээр суулгавал** програм удаан ажиллах, гацах, эсвэл үйлдлийн системээс шалтгаалсан тодорхойгүй алдаа гарах эрсдэлтэй.

# 🛡️ Антивирус програм блоклосон тохиолдолд [Anchor](https://docs.dayansoft.mn/erp/d014\#%F0%9F%9B%A1%EF%B8%8F-%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81-%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC-%D0%B1%D0%BB%D0%BE%D0%BA%D0%BB%D0%BE%D1%81%D0%BE%D0%BD-%D1%82%D0%BE%D1%85%D0%B8%D0%BE%D0%BB%D0%B4%D0%BE%D0%BB%D0%B4)

Зарим антивирусны програм Dayansoft ERP-г шинээр суулгах үед блоклох тохиолдол гарч болно.

Ийм үед тухайн антивирусны програмын **Pause protection / Disable protection** тохиргоог түр ашиглан суулгалтыг хийж болно.

### Алхам 1\. Антивирусны програмыг олох [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-1-%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D0%BD%D1%8B-%D0%BF%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D1%8B%D0%B3-%D0%BE%D0%BB%D0%BE%D1%85)

Компьютерын баруун доод буланд байрлах **Hidden icons** хэсгийг нээнэ.

![ShowHiddenIcons](https://docs.dayansoft.mn/user/pages/01.dkb/04.erp/04.d014/ShowHiddenIcons.png)

### Алхам 2\. Хамгаалалтыг түр зогсоох [Anchor](https://docs.dayansoft.mn/erp/d014\#%D0%B0%D0%BB%D1%85%D0%B0%D0%BC-2-%D1%85%D0%B0%D0%BC%D0%B3%D0%B0%D0%B0%D0%BB%D0%B0%D0%BB%D1%82%D1%8B%D0%B3-%D1%82%D2%AF%D1%80-%D0%B7%D0%BE%D0%B3%D1%81%D0%BE%D0%BE%D1%85)

Антивирусны програмын төрлөөс хамаарч цэс, нэршил өөр байна.

Жишээ нь:

- **Avast:**`Shield Control → Disable for 10 minutes`
- **Kaspersky:**`Pause protection → Pause`

> ⚠️ **Аюулгүй байдлын анхааруулга:**
> Антивирусны хамгаалалтыг зөвхөн **шаардлагатай хугацаанд түр зогсоож**, суулгалт дуусмагц хамгаалалтыг **буцаан идэвхжүүлээрэй**.
